# Minedrill's Beta Excavation Site

Minedrill's Beta Excavation Site is a COSMOS site, location unknown. This site is not static and needs to be scanned down.

  - Note:** The 3rd pocket contains Rogue Drones (Deal: Resist: **Varied**) instead of Caldari State.

  1. # 1st pocket

You land on the acceleration gate to the next room, however all enemies must be killed before the gate unlocks.
