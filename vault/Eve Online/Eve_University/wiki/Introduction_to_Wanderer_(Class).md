# Introduction to Wanderer (Class)

<onlyinclude></onlyinclude>

1. # Class Overview
Introduction to Wanderer familiarizes students with features and common practices related to Wanderer, a wormhole mapping application.

This class covers the following topics:

- Basic functionality
- Connections
- Map Settings (User)
- Map Settings (Global)
- Widgets
- API
- ACLs
