# Bookmarks (CORE class)

__NOTOC__<onlyinclude></onlyinclude>
1. # Class Overview
Introduction to Bookmarks teaches the basics of the Bookmarking system in EVE Online, how to create them and how to use them as insta (un)docks, safe spots and more.

This CORE class covers the following topics:

- What Are Bookmarks?
- Creating Bookmarks
- Types Of Bookmarks
- Organizing and sharing Bookmarks
- Q&A
