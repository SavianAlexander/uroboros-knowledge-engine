# EVE University Corporation Skill Plans

EVE University maintains many in-game Skill Plans for members looking for direction in skill training.

These plans are directly available to EVE University characters through the in game Skill Plan interface - and are also available to ANY character in the game using the instructions below.

None of these skill plans are mandatory for EVE University members.  The CORE category skill plans are highly recommended, however, as they provide access to many basic EVE University doctrine ships that allow participation in activities the University engages in!

1. # Accessing skill plans
There are two ways to access the corporate skill plans.  Both methods are available to EVE University members.  Non-member characters (including not only the EVE community at large, but alts of Uni members not directly in EVE University) must use the second method to access the plans.

  1. # EVE University members - skill plan interface
Members of EVE University can directly access the in-game skill plans through the **Skill Plan Interface > Skill Plans Screen > Corporation Plans**

  1. # All other characters - using plan links
Any non-EVE University character can access the EVE University Skill Plans, by using the link provided with each plan below, and the following instructions:
- Copy all text in the link for the plan you want to generate a link for, including the leading <url> and trailing </url>

- Paste the text into an in-game notepad page (**NEOCOM > Utilities > Notepad**)

- The notepad will automatically convert the pasted link text into an in-game link which can then be used like other in-game links.

1. # Using skill plans

The Corporation Skill Plan interface will present a list of available skill plans, as shown in the first image to the right.  Each plan will display its name, a progress bar showing trained skills (white), skills in the pilot's current skill plan (blue), and untrained/unplanned skills (grey).  The total time to complete the skill plan, using current pilot attribute mapping and implants, is displayed below the progress bar.

A Corporation may have up to 100 total plans saved for members to use.  The circular, numeric buttons at the lower left corner of the Corporation Skill Plan interface, can be used to change pages of displayed skill plans when a Corporation has more than 12 saved plans.

The "Create Plan" button at the lower right corner of the interface is only available for Corporation members with the "Skill Plan Manager" role, which enables adding, maintaining, and deleting Corporation Skill Plans.

Once a Corporate Plan is selected from the list, a pop-up window such as the second image to the right, will appear with the details of that skill plan.  The example image has several yellow-numbered areas, which are referenced below:

1) The skill plan Title

2) The skill plan Description.  EVE University Skill Plan descriptions will include:
- A synopsis of the skill plan, including what it is intended to be used for, and any special considerations (e.g. if the plan is Omega clone only)
- Any prerequisites - other Corporation Skill Plans which should be trained before tackling this plan
- Any other skills to train - some plans will have you choose a specific ship skill to train before/during/after the plan.  This is used when multiple options don't fit in well with the skill plan interface, without creating a separate plan for each option (e.g. a plan may have all of the support skills for a specific category of ship, then ask that you train the Racial ship skill of your choice - Amarr/Caldari/Gallente/Minmatar - to fly your preferred hull)
- A web address for the UniWiki article that addresses the plan
- A version number and last edited date

3) The Show/Hide Skill Plan Contents button opens or closes the panel of specific skills to the right.  The image shows the panel open.

4) Milestones and Progress: each in-game skill plan (Corporation or otherwise), can select up to five Milestones associated with the plan.  Milestones represent key points of progress within the plan - a plan that trains all five levels of a key skill, for example, may use Level V as a milestone, to show completion of that key skill.

Milestones may also be ships, modules, or items otherwise that are unlocked by the plan.  Plans are not required to have milestones, but milestones can help communicate the intent of the plan and are used in EVE University skill plans where possible.

The arc surrounding the milestones shows skill plan progress in the same way as the progress bar on the Corporation Skill Plans menu - showing trained skills (white), skills in the pilot's current skill plan (blue), and untrained/unplanned skills (grey).  The total time to complete the skill plan, using current pilot attribute mapping and implants, is displayed above the milestones.

5) Plan skillbooks - this image indicates whether all skillbooks required to train the plan are owned (shown in the image to the right), or if skillbooks are missing.  Interacting with this image will allow a pilot to purchase directly injectable skillbooks that are not owned.

6) The buttons below the milestones and progress images allow a pilot to interact with the skill plan.  The buttons from left to right are:
- Edit Skill Plan: for Corporation Skill plans, this function will only be available for Corporation members with the "Skill Plan Manager" role, which enables adding, maintaining, and deleting Corporation Skill Plan
- Save Skill Plan: this saves a copy of the plan to the pilot's personal skill plans.  Each character may store up to 10 personal plans at a time.  Corporation Skill Plans can be saved, which allows a pilot to edit the plan if desired.  Saving corporate plans is not necessary - they can be used directly from the Corporation plan list.  Saving a plan may make it easier for out-of-corp characters to access the plan, however, so they do not have to continue to use the link generation method to access the plan.
- Share Skill Plan: Drag this button into a chat channel to create an in-game link to the plan.  Useful for sharing the plans with out-of-corp characters, or to highlight their use in conversations.
- Delete Skill Plan: for Corporation Skill plans, this function will only be available for Corporation members with the "Skill Plan Manager" role, which enables adding, maintaining, and deleting Corporation Skill Plan
- Track Skill Plan: One skill plan at a time (Certified, Personal, or Corporation) may be tracked by a character.  This shows progress toward completing the plan in the character's skill interface, including as a ring around the thumbnail skill progress image below the character's image on the NEOCOM toolbar.  Tracking a plan is not required to use the plan.

7) The list of skills in the plan.  This panel is collapsible using the Show/Hide Skill Plan Contents button.

The contents of a skill plan are based on a character with zero levels in any skill, with pre-requisites enforced.  There will, therefore, be differences between the in-game skill list, and the UniWiki list of the skill plan on the plan-specific page.  UniWiki pages will often ignore skills such as character starting skills, or skills trained in a plan pre-requisite to the plan being viewed.  The in-game skill plans will not list those UniWiki ignored elements.

8) The hamburger menu in the upper right corner of the skill plan list, allows a pilot to copy the contents of the skill plan to the clipboard.  This is useful in exporting the list of skills to third party tools, such as EVEMON.

9) Pressing the Start Training button will add all of the untrained skills in the plan, to the character's skill queue.

1. # EVE University Corporation Skill Plans
Each EVE University Corporation Skill Plan is listed below.  The plans are grouped into loose categories based on the in-game "career" they were written to support.  This does not mean pilots interested in other in-game activities will not find use in the plans, so train what feels useful!

Each plan includes:
- Plan Name, matching the name of the plan in-game.  Clicking the plan name will load the wiki page that explains the plan in greater detail.
- Plan Synopsis - a short description of the plan
- Plan URL - for copying and using to access the plan on out-of-corporation characters

1. # Basic skill plans
The plans in this category were designed with Player versus Player (PvP) combat in mind.  Training into these plans increases the ability to participate in EVE University fleets of many different kinds.

Even players who feel they have no interest in PvP should consider the E-Uni CORE plans, as these plans provide a good base of skills for any **New Eden** pilot, and will enable access for joining fellow Unistas on events when the mood strikes!

While the plans are PvP focused - pilots interested in other activities may still find a solid base of skills in these plans (for example, characters focused on PvE combat will need a number of these skills!)

The E-Uni CORE Skill plan are core EVE University skill plans aimed at providing members with access to content quickly.  All members are encouraged to consider training this plan!

  1. # E-Uni CORE Skill Plan
The **E-Uni CORE Skill Plans** aim at getting new pilots into content fast.  There are multiple component plans - the first (CORE 6) aimed at getting pilots into basic small ships, with access to relevant weapons, inside of a few days of training.  The second (CORE 30) expands capabilities to more small sized ships. The third and last expands this to medium size ships and weapons.
