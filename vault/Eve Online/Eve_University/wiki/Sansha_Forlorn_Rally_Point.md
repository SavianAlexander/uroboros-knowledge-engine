# Sansha Forlorn Rally Point

The Sansha Forlorn Rally Point is a **combat anomaly** found in **Sansha** infested regions. It is a level 4 variant of the **Sansha Rally Point**.

1. # Walkthrough
Warping to beacon for close range would require a very good tank to handle the swarm’s incoming damage. Using a propulsion module or a Micro Jump Drive is recommended. Ship count vary as indicated. Single ungated normal space pocket.
