# Fitting (CORE class)

__NOTOC__<onlyinclude></onlyinclude>
1. # Class Overview
Introduction to Fittings teaches the basics of fitting a ship in EVE Online, what skills effect your fitting capabilities and how to decide which modules best to put on a ship.

This CORE class covers the following topics:

- The Ship Fitting Window
- Increasing a ship's fitting capacity via Skills and Modules
- Module Tech levels and sizes
- Scripted Modules
- Stacking Penalties
- 3rd Party Fitting Tools
- Q&A
