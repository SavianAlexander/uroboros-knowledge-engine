# Sansha Gas Processing Site

- Sansha Gas Processing Site** is a **hacking** site that can be scanned using Core Probes in Sansha infested territory in Low Sec space. This site appears to Probes as a Gas Site rather than the typical hacking site. It is also defended by hostile NPC ships.
1. # Walkthrough

A well-tanked T1 battlecruiser can run this site without much problems.
