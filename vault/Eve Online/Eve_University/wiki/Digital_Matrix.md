# Digital Matrix

- Digital Matrix** is a **chemical lab** found in Feythabolis region, especially in the I-3ODK constellation.

1. # Walkthrough

The site contains both combat and hacking. Using the acceleration gates in the site requires hacking IV to be trained.

The gate to fourth pocket is locked and requires a key. The key is found in the second pocket.
