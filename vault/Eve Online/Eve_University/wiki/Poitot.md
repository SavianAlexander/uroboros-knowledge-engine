# Poitot

- Poitot** [(Dotlan)](https://evemaps.dotlan.net/system/Poitot) is a system in the **NPC nullsec** region of **Syndicate**, relatively close to EVE University's **Null-Sec Community**.

In EVE Online's fictional "lore", Poitot is named in honor of an astronomer. It is the only named system in Syndicate, which has led to a running joke in which pilots remind each other that Poitot is the only named system in Syndicate.

There is a small in-game item with no actual use called "Postcard From Poitot", which has a description reading "Interesting fact: Poitot is the only named system in the Syndicate region." The Postcard From Poitot has some novelty value for players, and sells for a reasonable price in Jita.

Poitot has some practical in-game importance as part of the linear **pipe** joining "east" and "west" Syndicate.
