# PI Templates

<noinclude>Planetary Interaction (PI) Colony Templates can be used to store and import colony layouts. It is used to duplicate or recreate the same setup over different planets. They can be exported and shared between players. This can speed up the process of setting up multiple similar colonies or help inexperienced industrialists with setting up a colony.
1. # How to use PI templates

  1. ## Access the template window
  1. #### Save layouts
Layouts of already built colonies can be saved as a new PI template by pressing "Save as template" in the planetary build menu while in Planetary Industry View.

  1. #### Load layouts
Previously saved or imported templates can be accessed by pressing "Open template" in the same menu. This opens a new window called "Planetary Interaction Colony Templates", that lists the available templates.

With the  icon in the upper-left , entries can be in- or exported. Either to or from the clipboard or to/from a .json-file. Setups saved as a file will show up in the list.

The searchbar and the Filter icon can be used to limit the templates that are shown in the list.
</noinclude>

A template can be shared as .json-file or by clipboard. To import a template from wiki, mark and copy the contents of the template-box to the clipboard. Open the Template list ingame by "Open Templates" and  "Import & Export". "Load from clipboard" to build from the template. "Save from clipboard" to insert the template to the list for later use.
