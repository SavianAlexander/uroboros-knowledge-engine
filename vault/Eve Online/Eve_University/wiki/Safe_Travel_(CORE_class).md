# Safe Travel (CORE class)

__NOTOC__<onlyinclude></onlyinclude>

1. # Class Overview
This CORE class looks into tools, ship fits, and system mechanics to help travel through New Eden more safely.

- Tools to anticipate danger and plan your travel route
- Triglavian and Edencom gate camps/guns
- Ships, skills, and modules to help you move around more safely
- Nuances in different security systems
- Scenarios
