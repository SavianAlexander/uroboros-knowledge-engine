# Booster Manufacturing (Exile)

<noinclude>
  - Serpentis COSMOS** mission
Agents: **Goligere Debanelis**, **Gomosabin Zerdanne**, **Juvoire Sche**, **Oguet Aene**, **Ravacesel Roque**
Standings required: None

  - Booster manufacturing** is a single run mission found in null security COSMOS constellations. Each agent will give this mission only once.</noinclude>

Simple trade mission where the agent requests some cytoserocin and gives drug BPC as a reward. The gas can be mined locally if you have venture or prospect and core probes. Alternatively you can use a blockade runner or prospect to haul the gas from elsewhere. This mission can be completed once for each agent (**Goligere Debanelis**, **Gomosabin Zerdanne**, **Juvoire Sche**, **Oguet Aene**, **Ravacesel Roque**).
