# Hidden Ruins

The following info is unconfirmed. It is modified from a similar site in a different region. 
  - Hidden Ruins** is a very rare Relic site involving combat as well as **hacking**, found by scanning in Nullsec. It is found in the Cloud Ring region, and is probably found in the Syndicate and Outer Ring regions. Rats from several factions are present here. Up to T2 **Battleships** can enter the site. Damage in the site can easily become excessive if care is not taken in managing triggers.

1. # Walkthrough
The warpin contains a few rats. 

The acceleration gate is locked until the defenders are dead.
