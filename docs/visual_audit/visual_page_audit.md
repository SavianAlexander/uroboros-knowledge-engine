## 🔍 Layout Quality Checklist

| Rule | Description | Status |
| :--- | :--- | :---: |
| **No Orphan Headers** | Headers (`#`, `##`, `###`) must have at least 3 lines of paragraph text beneath before page breaks. | Verified |
| **No Pagination Leakage** | Trailing 1–2 sentences must not spill over onto a new blank page. | Verified |
| **No Table Cuts** | Table headers must not separate awkwardly from data rows across pages. | Verified |
| **Balanced Page Budgets** | Document layouts must not exhibit large white space gaps or premature pagebreaks. | Verified |
