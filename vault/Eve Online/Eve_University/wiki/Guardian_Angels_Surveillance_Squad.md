# Guardian Angels Surveillance Squad

- Guardian Angels Surveillance Squad** is an expedition that escalates from **Provisional Serpentis Outpost**.

1. # Walkthrough

The first three locations are usually in low security space while the last location is usually in null security space but this varies.

  1. # First Location
----
Warp in. If Shadow Serpentis is there: kill him, possibly get escalation. Else (or If didn't get escalation): Use acceleration gate, kill Serpentis Security Station (if present), possibly get escalation.
