# Contested Gallentean Canyon of Rust

- Contested Gallentean Canyon of Rust** is an **Gallente COSMOS** site in Alsottobier system in Algintal constellation. It is farmed very heavily.

This site is rumored to respawn four times a day and contain overseers that can drop faction modules and Gistii A-Type modules. This may not be true anymore.

The warpin contains only an Ancient acceleration gate to Wiyrkomi Engineering Outpost. 

The maximum size Ship that can be used to enter the acceleration gate is a battlecruiser-size ship.

1. # Wiyrkomi Engineering Outpost

This pocket contains few structures and an acceleration gate to Infested Comet Remains (90 km). The Algintal Luxury Resort drops commodity drugs (Drop, Mindflood, Sooth sayer). 

There are rumors of a overseer ship "Wiyrkomi Head Engineer" that can drop shadow serpentis items. I have encountered this enemy, but not received Shadow Serpentis items; only overseer's effects.

1. # Infested Comet Remains

This pocket contains drone infested asteroids and serpentis structures. Gate to next room is 20 km from warpin.

The rats in this room are rumored to respawn every three hours. I have encountered The Negotiator recently(September 2023), but the negotiator only dropped 8th Tier overseer's personal effects.

Negotiator point is unconfirmed.
