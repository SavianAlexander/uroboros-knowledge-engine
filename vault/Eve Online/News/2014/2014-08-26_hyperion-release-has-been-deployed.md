We are happy to announce that the Hyperion release has been deployed succesfully!

This release includes a whole host of updates, improvements and features, including new level 4 “[Burner” missions](//community.eveonline.com/news/dev-blogs/size-matters-introducing-burner-missions/), [wormhole updates](//community.eveonline.com/news/dev-blogs/into-the-known-unknowns/), [Incursion changes](//community.eveonline.com/news/dev-blogs/incursion-changes-in-hyperion/), [overview improvements](//community.eveonline.com/news/dev-blogs/sharing-is-caring/), and further functionality in [EVE Online’s API system](//community.eveonline.com/news/dev-blogs/what-third-party-developers-probably-want-to-know-about-hyperion/).

You can read an overview of all the improvements and features that arrived with the Hyperion release in the [“Coming in Hyperion”](//community.eveonline.com/news/dev-blogs/coming-in-hyperion-on-august-26th/) Dev Blog, by CCP Seagull, Executive Producer for EVE Online, and check out the [full patch notes](//community.eveonline.com/news/patch-notes/patch-notes-for-hyperion) on the Community Portal.

For general feedback on the Hyperion release, please use [this thread](//forums.eveonline.com/default.aspx?g=posts&m=4952650). To report issues and problems, please use [this thread](//forums.eveonline.com/default.aspx?g=posts&m=4952651).
