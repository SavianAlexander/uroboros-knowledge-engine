Best Internet Spaceship pilots!

Today on August 27, 2012, we have reached another milestone with opening DUST 514 on our test server Singularity for EVE players.

[DUST 514 was moved to Singularity](//community.eveonline.com/news/newsFromEve.asp?newsTitle=dust-514-moving-to-singularity) earlier last week and available there for DUST players. Since then we have worked hard to ensure that interaction between DUST and EVE is possible and stable. This is the first time that players from both EVE and DUST 514 can interact like this on a public (test) server - quite a revolutionary step and we gladly share this moment with you.

Check out CCP Habakuk's forum thread [here](//forums.eveonline.com/default.aspx?g=posts&t=148266) for all the details!

Information how you can connect to our Singularity test server can be found [here](//forums.eveonline.com/default.aspx?g=posts&t=6352).
