# Wormhole Living (Class)

__NOTOC__<onlyinclude></onlyinclude>
1. # Class Overview
Wormhole Living introduces the basics of living in a Wormhole. It will give an overview over what difficulties one might face, how much time, ISK and effort might be envolved and how to go about it.

This class covers the following topics:

- Settling vs Nomadic
- Why live in a Wormhole?
- Structures
- Wormhole Effects
- Where to live
- Defence
- Q&A
