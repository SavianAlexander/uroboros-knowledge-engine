# Guristas Yard

- Guristas Yard** is a **combat anomaly** found in Caldari low and null security systems with **Guristas** presence.
1. # Walkthrough
The site is an open deadspace pocket; a player can warp to it at any preferred distance. The next wave is triggered when the last rat from the previous wave is destroyed.
