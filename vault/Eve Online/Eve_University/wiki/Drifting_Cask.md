# Drifting Cask

- Drifting Cask** is a **Amarr COSMOS** site in system of Zimse. It needs to be scanned down and will respawn in the same system immediately.

1. # Warp-in
There are two variants of the site.

If the site has defenders the cask will contain Amolah Kesti's Data Fragment I. The container is locked until all defenders are dead.

If the site has no defenders then the cask will contain Amolah Kesti's Data Fragment II or Amolah Kesti's Data Fragment III.

The site can be run in a properly tanked battlecruiser.
