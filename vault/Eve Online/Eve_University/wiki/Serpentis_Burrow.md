# Serpentis Burrow

A **Serpentis Burrow** is a **cosmic anomaly** found in high security Gallente space. There are two minor variations with slightly different wave compositions. Which variation a given anomaly is can only be determined by warping to it.

1. # Asteroid station
This variation features a prominent asteroid station object.
