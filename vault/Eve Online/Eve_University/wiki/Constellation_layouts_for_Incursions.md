# Constellation layouts for Incursions

1. # Constellation layouts
The number of systems in the constellations will determine how many of each type of sites there will be. The split between the systems will follow certain criteria, but doesn't change from one time to another. So each constellation layout will remain the same unless CCP decides to change things again, like they did in the [Rubicon 1.2](https://www.eveonline.com/news/view/patch-notes-for-rubicon-1.2) point-release back in February 18th, 2014.
- There will always be a single staging system with scout sites.
- There will always be a single system with headquarter sites (including the mothership site).
- There will always be at least one or more systems with vanguard sites and one or more systems with assault sites.
  - If there are enough systems to have more than three vanguard systems, an additional assault system will be added before adding a fourth vanguard system. And before adding a fifth vanguard system, a third assault system will be added.
- Systems with a different security than the constellation in general, like low security systems in a predominantly high security constellation, are not part of the incursion.
- In general the systems will spawn "out" from the Scout/Staging system with Headquarters being as far away as possible and Vanguard systems being adjacent to the Staging system.

For more information about the spawn mechanics etc, see **number of Incursions and respawns** and for a list of active incursions as well as recent data, see **dotlan's** [incursions](https://evemaps.dotlan.net/incursions) or **Shadowlauch's** [EVE-Incursions](https://eve-incursions.de) page.

Before you add a constellations and its systems to this list, make sure that you've covered all the systems in the constellation. Open up the constellation information, easily accessible by the linked system name in the **journal** under the **Incursions** and **Global Report** tabs. Click the constellation name in question and look under **Related Solar Systems** to verify the systems and then visit each system in turn to check which type of system it is. That way we can make sure we don't miss a system or add one that isn't in the constellation in question, or mislabel a system of a different type of system than it is. Don't assume other sites or people have done this, double-check for yourself before adding this information.

If you see a new constellation spawn, feel free to add it with just the link to the dotlan maps. Even if you don't go there to scout out the systems, we'll know that the constellation is part of the rotation.
