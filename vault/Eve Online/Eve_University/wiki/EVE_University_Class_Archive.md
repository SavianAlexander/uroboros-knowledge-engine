# EVE University Class Archive

__TOC__

  - The EVE University Class Library is currently being refreshed.** Some older classes containing out of date information have been removed. Many of the classes retained here have been kept for their historical interest, as they involve famous players and developers. The University is developing a new set of up-to-date class recordings.

If you are looking for the classes we commonly teach visit **Classes**.  If you are looking for a list of upcoming classes visit [Scheduled Classes](https://forum.eveuniversity.org/viewforum.php?f=72).

If you're interested in teaching a class, find out about **teaching classes at EVE University**.

1. # Recording formats

  - Download Options**
- Audio from the [YouTube Videos](https://www.youtube.com/channel/UClYJb-ArhtPFJBLwvy0nXMw) can be downloaded for offline listening using services such as [ClipConverter](https://clipconverter.cc/).
- Files hosted at **EVE University Server** can be streamed or downloaded directly.
- Files hosted at **Eve Files** can be downloaded directly or by using a bittorent client
- Other hosting sites might require you to wait a short while before you download.

  - Formatting**
- **Date: YYYY.MM.DD**
- **Length: MMM:SS**
