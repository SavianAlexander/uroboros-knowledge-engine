# Dust 514: Skill Books

1. # Skill Books in Dust 514

Skill books in Dust 514 have the same function as they do in EVE. Once purchased a new skill is made available for use by your Merc. They can be purchased either in the Marketplace or direct from **The Skill Tree**.

These improve with each activated Skill Level up to Level 5. Access to other skills can also be allowed once a particular skill has reached a certain level. This is known as a *prerequisite*.

There is a basic Skill Point requirement for each skill. This is known as the *Training Cost Multiplier*.

1. # Training Cost Multiplier

The base Training Cost Multiplier, or **x1** is as follows:

  - Level 1** = *6220* SP

  - Level 2** = *18,650* SP

  - Level 3** = *43,530* SP

  - Level 4** = *87, 060* SP

  - Level 5** = *155,460* SP

So the total SP requirement to get a base **x1** skill to Level 5 is 310,920 SP.

As an example, the Weaponry skill has a **x1** Training Cost Multiplier but the Caldari LAV (Light Attack Vehicle) skill has a **x8** Training Cost Multiplier. Meaning that it requires 8 times the number of SP that a **x1** skill like Weaponry needs per level.

As of the open beta the Training Cost Multiplier of various skills are **x1**, **x2**, **x3**, **x4**, **x5**, **x6**, **x8**, **x10** and **x12**.
