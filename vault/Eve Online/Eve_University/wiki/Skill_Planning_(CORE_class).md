# Skill Planning (CORE class)

__NOTOC__<onlyinclude></onlyinclude>
1. # Class Overview
Skills are the fundamental EVE mechanic by which our characters gain access to the various activities, ships, and modules with which we live our lives in New Eden. If you are looking to understand more about the anatomy of skills, how to skill plan, or which skills affect everything you do in EVE, this is the class for you!

This CORE class covers the following topics:

- Anatomy of a Skill
- Skill Queue
- Training Skills Faster
- Skill Planning Strategies
- EVE Uni Skill Plans - Short Skill Plan and Pyramid Skill Plan
- Q&A
