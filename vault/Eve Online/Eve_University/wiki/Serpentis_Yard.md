# Serpentis Yard

- Serpentis Yard** is a class 5 **combat anomaly** found in low security space.

1. # Combat details

All ships spawn at 0 on the site.  Each successive wave is triggered by killing the last ship in the previous wave.

1. # Type 1: Silos
Also has 30x Veldspar Asteroids
