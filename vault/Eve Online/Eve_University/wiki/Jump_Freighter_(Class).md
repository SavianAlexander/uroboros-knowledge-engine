__NOTOC__<onlyinclude></onlyinclude>
1. # Class Overview
This Class introduces Jump Freighters and their mechanics in EVE. It formerly revolved around a practical session on the test server **Singularity**.

This class covers the following topics:
- What is a Jump Freighter(JF)?
- Differences between the four racial JFs
- What skills do I need to fly a JF?
- How to move a JF through HS, LS, NS?
  - How do I use Cynos?
  - What is a webbing alt?
- How do I fit my JF?
- How to avoid Suicide Ganker?
- How to 'plus jump'?
