# Pulverize the Pioneers

- Pulverize the Pioneers** is an expedition escalated from **Haunted Yard**.

1. # Walkthrough
The first three locations are generally in high security space and last in low security space but this can vary. 

The first three locations can be done in a T1 frigate at range, though for the last location a high DPS destroyer or a cruiser is advised.

1. # Loot

The commander drones in sites drop drone components and can also drop Rogue Drone 46-X Nexus Chip (Astero) or a faction module. The container in last location contains T2 salvage.
