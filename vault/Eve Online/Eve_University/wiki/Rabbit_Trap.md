# Rabbit Trap

<noinclude> </noinclude>

Single gated deadspace pocket. If you are running this mission in a Tech I destroyer with moderate skills (for example a **Thrasher**), it might be quite challenging to break Yukiros' shield. Use kinetic ammo.

The mission can be accepted remotely but you need to return to the agent to complete.

The pocket will be initially empty for about 20 seconds. Wave 1 spawns about 60 km off the warp-in.

|}

The despoilers will use ECM.

|}

Yukiro Demense uses rail guns and will try to stay far from you. He has -75% web at 10 km and warp disrupts out to 24 km. He has strong buffer shield tank with little regen, weakest resist to Kinetic at 64%.
