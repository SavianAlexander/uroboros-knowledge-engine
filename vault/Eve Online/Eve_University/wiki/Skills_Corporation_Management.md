# Skills:Corporation Management

# Overview
This skill category is trained by people who want be involved with creating and managing player owned corporations. Running a well-oiled operation is a fine art, and these skills are your brushes.

Memory and Charisma are needed to become skilled in the subjects in this category.

The following are the skills in the Corporation Management section (in alphabetical order):

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Corporation Management|mult=yes}} | Base skill required to create a player-run corporation. | Corporation Management}} |
| Diplomatic Relations|mult=yes}} | Corp management skill that reduces the cost to hire allies. | Diplomatic Relations}} |
| Megacorp Management|mult=yes}} | 2nd tier corp management skill allowing more corp members | Megacorp Management}} |
| Empire Control|mult=yes}} | 3rd tier corp management skill allowing more corp members. | Empire Control}} |
| Sovereignty|mult=yes}} | 4th tier corp management skill allowing more corp members. | Sovereignty}} |
