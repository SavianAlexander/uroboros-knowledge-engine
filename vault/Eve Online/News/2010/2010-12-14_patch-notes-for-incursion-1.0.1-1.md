**Patch notes for Incursion 1.0.1**

Deployed Wednesday, December 14, 2010

Table of Contents[FEATURES](//myeve.eve-online.com/updates/patchnotes.asp?patchlogID=215#features)[FIXES](//myeve.eve-online.com/updates/patchnotes.asp?patchlogID=215#fixes)

**FEATURES**


- Learning skill Removal - All learning skills were removed from characters, and the skill points were reimbursed. See [this](//wiki.eveonline.com/en/wiki/Skill_Reimbursement) EVELopedia article for how to use them.
  - All learning skills in hangars were reimbursed at their market value, paid out to the owning entity.
  - All learning skills in contracts were reimbursed at their market value and replaced with Pax Amarria
  - For more details, please see [this](//www.eveonline.com/devblog.asp?a=blog&bid=824) splendid Dev Blog by CCP Greyscale.
- Neural Remap window overhaul - Our UI designers and programmers were in holiday mood, and overhauled the Neural Remap window, making it much more intuitive. Why not check it out and see if any other gifts await you there!
- The Echelon has been released to capsuleers everywhere, just in time for the holiday season. For more information, see this [spiffy Dev Blog](//www.eveonline.com/devblog.asp?a=blog&bid=830).


**FIXES**


- **Drones** - Fixed fallout from the Fighter Bomber upgrade released in Incursion 1.0.0. This was causing Fighter Bombers to function erratically when sent to pursue targets.
- **Skills** - The Training Queue window is now updated for when you apply free skill points.
- **User Interface** - Context menu options for remote selling and contract creation were temporarily unavailable, this has been remedied.
  - An issue that caused players to no longer see an option to ‘Sell this item’ in the contextual menu while in space has been fixed.
- **Exploration and Deadspace** - Angel Cartel Naval Shipyard no longer requires learning skills to go through.
- **API** - The SkillTree now has a published(bool) value on each skill.
- **Market Contracts** - Contracts can again be created straight from items in a corporation hangar.
- **Mac** - The Mac client now supports anti-aliasing.
- **Miscellaneous**
- - Several issues that were causing the Trinity graphics engine to crash the client have been corrected.
  - Clarified the error message you receive when trying to sell an unpackaged item or ship.
  - Context menu options for remote selling and contract creation were temporarily not available, this has been remedied.
  - The dbo.invFlags table in the SDE had flagName and flagText switched. This has been corrected in the Static Data Dump.
  - Several exploits were fixed making the universe a better place for all.
