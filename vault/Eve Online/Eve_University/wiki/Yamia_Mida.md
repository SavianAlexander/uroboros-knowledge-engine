# Yamia Mida

- Yamia Mida** is an **Amarr COSMOS** combat site found in Zimse system. The site respawns in the same system after completion so you will need to scan it down yourself.

The site consists of single ungated pocket.

Kill the defenders and grab Yamia Mida's Remains.
