# Mission Hubs

Some players who run missions will aim to try to build up standings with particular NPCs corporations. For this objective it helps if one can run missions for the corporation that also directs to a Storyline Agent of the same corporation every 16 regular missions because not only does faction standing increase with **Storyline mission**s but corporation standing also increases.

For every 16 missions of the same faction and level that are completed you get a storyline offer from the nearest Storyline agent of the same faction and the mission offered will be of the same level (Storyline Agents transcend levels). "Nearest" is determined by the number of Stargate jumps from the regular agent who gave you the 16th regular mission. There are two exceptions. First, if you already have an Offered or Accepted mission from the nearest Storyline Agent that you haven't declined, failed, or completed yet, then your next offer will come from the second-nearest Storyline Agent. Second, if your 16th regular agent is in High Security then you will never get the triggered storyline offer from any Storyline agent in Low Security. (However, depending upon their proximity to LowSec, the mission might send you into LowSec.)

If two or more such storyline agents are equally distant then it's random as to which agent will send you an offer.

1. # Explanation of Additional Information
These tables are organized in the interest of popping storyline missions of the particular faction. As such, any row that has a &#11162; under the system name indicates that performing missions in this system - even for agents not of the faction listed in the particular table - will pop a storyline mission in the listed system

- **Redirect** - In the case of Factions who have Agents for regular missions, the Redirect note indicates that completing missions in this system for this faction will pop storyline missions for the named faction.  For example, Emolgranlan only has a single Level 1 regular agent in Brutor Tribe and if this agent gives you your 16th Level 1 Minmatar Republic mission then the nearest Storyline Agent of the Minmatar Republic works for the Republic Security Services corporation. In the case of Factions that have no regular agents, this is the faction that you should be doing missions for in order to pop a storyline from the concerned faction. If a storyline agent of a different corporation is equidistant from a storyline agent of the same corporation then this will also be noted as "may redirect to" or "OR"
- **HiSec Pocket** - This system is located in a High Security Pocket system, with only one way in/out of the "pocket" at large ( a pocket may consist of multiple systems).
- **Adj LowSec (#/#)** - This system has jumps to LowSec systems. The numbers indicate how many go to LowSec and how many total gates there are. These systems are useful for triggering LowSec Storyline missions.
- **Research** - The Research column indicates agents in the Research division; you need Science Level 5 and other related skills to start research projects. If you don't intend to farm datacores then Research agents are irrelevant to you.
