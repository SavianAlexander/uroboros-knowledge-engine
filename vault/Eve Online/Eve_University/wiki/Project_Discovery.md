# Project Discovery

- Project Discovery** is a citizen science project that brings real world science data problems in EVE For players to look at.

So far there have been three phases.
- **Project Discovery: Human Protein Atlas**
- **Project Discovery: Exoplanets** (Phase 2)
- **Project Discovery: Flow Cytometry** (Phase 3/Phase 4)
