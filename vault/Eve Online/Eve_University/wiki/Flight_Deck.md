# Flight Deck

Flight Deck is a program that provides fitted ships for free by EVE University for its members to use. Please only take what you are going to use immediately to ensure they are available to everyone. However, they are there to be used, enjoyed, blown up and taken again so feel free to take replacements for any FD ships you have lost. They can be found on contract in Korsiki - Horizon. The full fits and explanations about each fit can be found on [Alliance Auth](https://auth.eveuniversity.org/fittings/doctrine/4/)

1. # Finding Flight Deck ships

Flight deck ships are provided on corporation **contract**s. To find them, use the contract search window through **Neocom**() > Finance() > Contracts().

Once the contract window is open, make sure to select the Contract Search tab, select the Buy & Sell sub-tab and set the options on the left sidebar as follows. If you don't see some of these options, make sure to Show More Options.
- Search field = the hull you want (The field remembers the last search and shows "Item Type" when empty)
Set the filters to:
- Location = select the relevant location such as Current System or Pick Location > Korsiki
- Contract Type = select All
- Item Category = select All
- Uncheck Exclude Multiple Items
- Uncheck Exact Type Match
- Price = 0 To 1 (million)
- Availability = select My Corporation
- Security Filters = check as relevant
- Issuer = blank
If you aren't able to find any results, make sure results aren't being filtered out by the Page Filters. Page filters can be modified at the bottom of the contract search page and expanded or hidden using the up/down arrow icon.
