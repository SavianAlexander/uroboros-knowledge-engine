# Skills:Fleet Support

# Overview
Fleet Support skills improve the use of **Command Bursts**, which increase the performance of all ships in the user's fleet.

Charisma and willpower is needed for those who wish to command.

The following are the skills in the Leadership section (in alphabetical order):

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Armored Command|mult=yes}} | Increases duration of Armored Command Burst effects. | Armored Command}} |
| Armored Command Specialist|mult=yes}} | Increases the strength of Armored Command Burst effects. | Armored Command Specialist}} |
| Command Burst Specialist|mult=yes}} | Reduces reload time for command burst modules. | Command Burst Specialist}} |
| Expedition Command|mult=yes}} | Basic proficiency at boosting the scanning and hacking capabilities of allied ships. | Expedition Command}} |
| Expedition Command Specialist|mult=yes}} | Advanced proficiency at boosting the scanning and hacking capabilities of allied ships. | Expedition Command Specialist}} |
| Fleet Command|mult=yes}} | Increases command burst area of effect. | Fleet Command}} |

| Fleet Coordination|mult=yes}} | Advanced fleet command skill that unlocks different fleet sizes and spacing. | Fleet Coordination}} |
| Fleet Formations|mult=yes}} | Fleet command skill that unlocks custom fleet formations. | Fleet Formations}} |
| Information Command|mult=yes}} | Increases duration of Information Command Burst effects. | Information Command}} |
