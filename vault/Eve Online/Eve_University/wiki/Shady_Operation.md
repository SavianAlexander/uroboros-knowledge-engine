# Shady Operation

- Shady Operation** is an **Expedition** that can escalate from **Sansha Fortress**.
1. # Walkthrough
All four parts are in Sansha infested nullsec. The first two locations are ungated, while the last two have acceleration gates which permit subcaptials.

  1. # First Location
Large number of ships at warpin. If True Sansha does not spawn or trigger escalation, destroy Gruel Minjoan to escalate site.

|}

  1. # Second Location
