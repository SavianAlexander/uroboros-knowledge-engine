1. # Summary
The Ixion is the Angel Cartel's logistics cruiser. It is unavailable for use by players, but it has been included in the wiki for the sake of completeness and the hope CCP will make it playable at some point in the future.

1. # Notes
Getting stats for the Ixion was problematic due to how the vessel has been removed from the database, but dedicated searching turned up an entry for it on [old.eve-ru](http://old.eve-ru.com/index.php?type=component&mid=12&comid=5&typeID=636). The ship's original description was simply "Pirate Cruiser 1", while the current description was taken from [the ♦ Ixion entry on EVERef](https://everef.net/type/43642). The attributes and stats had to be assembled from other sources, but since the ship has been removed from the database their accuracy is neither guaranteed nor particularly relevant except for historical purposes.
