The latest build on Singularity now features stunning [new nebulae](//www.eveonline.com/devblog.asp?a=blog&nbid=3057) which will add immersion to space throughout Tranquility. We have prepared a forum thread in the Test Server Feedback forum which you can see [here](//forums.eveonline.com/default.aspx?g=posts&t=29713&find=unread). We would ask as many of you as possible to check them out and give us some feedback.

In addition, this latest Singularity build has new battlecruisers, new Tech II modules, hybrid rebalancing and much more. Check it out and see the myriad of threads for feedback in the [Test Server Feedback forum](//forums.eveonline.com/default.aspx?g=topics&f=271).
