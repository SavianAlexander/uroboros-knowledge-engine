# Skills:Targeting

# Overview
This has all the targeting related and all the “Sensor Compensation” skills, which help pilots lock onto more targets, faster, and at longer ranges.

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Advanced Target Management|mult=yes}} | Further bonus to max number of lockable targets; +1 per skill level up to ship's max allowed. | Advanced Target Management}} |
| Gravimetric Sensor Compensation|mult=yes}} | Increases resistance to Gravimetric ECM. | Gravimetric Sensor Compensation}} |
| Ladar Sensor Compensation|mult=yes}} | Increases resistance to Ladar ECM. | Ladar Sensor Compensation}} |
| Long Range Targeting|mult=yes}} | Bonus to targeting range. | Long Range Targeting}} |
| Magnetometric Sensor Compensation|mult=yes}} | Increases resistance to Magnetometric ECM. | Magnetometric Sensor Compensation}} |
| Radar Sensor Compensation|mult=yes}} | Increases resistance to Radar ECM. | Radar Sensor Compensation}} |
| Signature Analysis|mult=yes}} | Bonus to Scan Resolution. | Signature Analysis}} |
| Target Management|mult=yes}} | Increases max number of lockable targets; +1 per skill level up to ship's max allowed. | Target Management}} |
