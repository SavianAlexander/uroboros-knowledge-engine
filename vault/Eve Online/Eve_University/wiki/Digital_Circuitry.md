# Digital Circuitry

- Digital Circuitry** is a **chemical lab** found in Catch region.

1. # Walkthrough

The site contains both combat and hacking. Using the acceleration gates to the site requires hacking IV to be trained.

The gates leading to the last room can be used without killing the defenders.
