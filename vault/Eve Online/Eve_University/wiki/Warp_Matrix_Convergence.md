# Warp Matrix Convergence

Warp Matrix Convergence is a relic site that existed during the **Interstellar Convergence** event. It appears in high-sec where it must be scanned down and contains seven Peculiar Debris Fragments (one large, two medium, four small) which can be accessed using a Relic Analyzer module. The fragments contain some salvage and materials used to build the filaments of the event. Additionally Paradoxical Nebula fireworks, boosters and skins can be found.

The site is in a small region with lots of lightning and wormhole-like activity; there are a number of Convergent Accelerant Nexus and Convergent Decelerant Nexus spots which when approached by a spaceship apply various modifications to it, lasting for a minute.
