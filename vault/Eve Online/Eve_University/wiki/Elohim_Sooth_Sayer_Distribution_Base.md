# Elohim Sooth Sayer Distribution Base

- Elohim Sooth Sayer Distribution Base** is a **Chemical Lab** site that must be **scanned** using probes.

A data analyzer module will be required to open the cans in this site.

6 Cans
- 2x Com Relay
  - 2x 17 Successful Torture Techniques
  - 2x Navigation for Dummies
  - 1x Me, Myself and Plunder
  - 1x Pillaging 101
  - 1x Neurotoxin Control
  - 1x The Little Pirate That Could
- 3x Gadget Gasket
  - 3x Standard Sooth Sayer Booster Blueprint (50 Copy)
  - 1x Standard Sooth Sayer Booster Reaction
- 1x Novelty Box (1 Can)
  - 1x Strong Sooth Sayer Booster BPC (50 Run)
  - 1x Divine Opium

|}
- More Battleships and Cruisers spawn if you kill the last Battleship. The best approach is to leave the last Battleship and tank the damage while you open the cans.
- No Secondary Spawn - 26/12/2013

1. # Recommended Ship
A well tanked **Battlecruiser** (May need to warp out so make sure you have someone still at the site) or a **Heavy Assault Cruiser**
