# Basic skills

These are basic skill recommendations. None of these skills have prerequisites above level III, and are thus easily accessible to new players. They will provide a solid foundation upon which to develop more advanced skills and fit more advanced modules. 

The list has been grouped to match the in-game Skill categories. Some of the skills below are useful in your early days only to use some basic modules; others will increase your ship's performance directly and should be trained up to level II or III relatively fast. Where applicable which races of ship commonly benefit from a skill are included in parenthesis, but understand that the racial bonuses of a ship are not always a limiting factor of advanced player choices.

Take a look at the skill descriptions to see how they would help you, but understand that the description text does not always reveal the variety of useful skills and modules it unlocks as you train higher. There may be some overlap with the **The Magic 14** in this list also. Try using an application like PYFA that lets you see how a ship's attributes are affected by skills. EVEMon is another popular program that will let you plan skill training for your character. These and other useful programs and websites are linked in the **3rd Party Tools** article. 

1. # Armor

- : *5% bonus to armor hit points per skill level.*
- : *5% bonus to structure hit points per skill level.*
- : *5% reduction in repair systems duration per skill level.*

1. # Drones

- : *5% Bonus to drone damage of light drones per level.*
- : *5% Bonus to drone damage of medium drones per level.*
- : *Can operate 1 drone per skill level.*
  - This is a crucial "gateway" skill, and training to level III is required for the Light and Medium skills mentioned above. Levels IV and V open up a wide variety of other crucial **support skills**.
- : *Drone control range increased by 5000 meters per skill level.*

1. # Electronic Systems

- (Caldari) : *5% less capacitor need for ECM and ECM Burst systems per skill level.*
- : *10% bonus to falloff for ECM, Remote Sensor Dampeners, Tracking Disruptors,Tracking Links, Remote Sensor Boosters and Target Painters per skill level.*
- : *10% bonus to optimal range of ECM, Remote Sensor Dampers, Tracking Disruptors, Tracking Link, Remote Sensor Boosters and Target Painters per skill level.*
- : *5% reduction to warp scrambler, warp disruptor, and stasis web capacitor need per skill level.*
- (Gallente) : *5% less capacitor need for sensor link per skill level.*
- (Minmatar) : *5% less capacitor need for target painters per skill level.*
- (Amarr) : *5% less capacitor need for weapon disruptors per skill level.*

1. # Engineering

- : * 5% reduction in capacitor recharge time per skill level.*
- : *5% Bonus to ship CPU output per skill level.*
- : *5% reduction of CPU needs for all modules requiring Electronics Upgrades per skill level.*
- : *5% reduction in CPU needs of modules requiring Energy Grid Upgrades per skill level.*
- : *5% Bonus to ship's PowerGrid output per skill level.*
- : *5% reduction per skill level in the CPU needs of weapon turrets, launchers *(aka missiles)* and smartbombs.*

1. # Gunnery

- : *2% Bonus to weapon turrets' rate of fire per skill level.*
- (unnecessary for projectile weapons) : *5% reduction in capacitor need of weapon turrets per skill level.*
- : *5% bonus per skill level to weapon turret tracking speeds.*
- (Amarr) : *5% Bonus to small energy turret damage per level.*
- (Caldari and Gallente) : *5% Bonus to small hybrid turret damage per level.*
- (Minmatar) : *5% Bonus to small projectile turret damage per level.*
- : *4% bonus per skill level to weapon turret rate of fire.*
- : *5% bonus to weapon turret optimal range per skill level.*

1. # Missiles

- : *10% bonus to all missiles' maximum flight time per level.*
- : *2% Bonus to missile launcher rate of fire per skill level.*
- : *10% bonus to all missiles' maximum velocity per level.*
- : *3% bonus to missile launcher rate of fire per level.*
- : *5% Bonus to light missile damage per skill level.*
- : *5% bonus to rocket damage per skill level.*
- : *10% decrease per level in factor of target's velocity for all missiles.*

1. # Navigation

- : *5% Bonus to Afterburner and MicroWarpdrive speed boost per skill level.*
- : *5% reduction to afterburner duration and 10% reduction in afterburner capacitor use per skill level.*
- : *5% improved ship agility for all ships per skill level.*
- : *10% reduction in afterburner capacitor needs per skill level.*
- : *5% reduction in MicroWarpdrive capacitor usage per skill level.*
- : *5% bonus to sub-warp ship velocity per skill level.*
- : *Each skill level reduces the capacitor need of initiating warp by 10%.*

1. # Neural Enhancement

- : *Allows the use of cybernetic implants.*
  - Cybernetics can be trained up to level I only, as this gives access up to +3 attribute implants which is sufficient for a new pilot's early career and wallet.
- : *Allows 1 jump clone per level.*
  - Having multiple jump clones is readily accessible to new players by joining corporations with jump clone standings.

1. # Planet Management

- : *Each level in this skill improves the quality of command facility available to you, in turn allowing for a greater number of connected facilities on that planet.*
- : *For each level in this skill, you may install a command center on one additional planet, to a maximum of 6 planets.*

1. # Production

- : *3% reduction in all manufacturing and research times per skill level.*
- : *4% reduction in manufacturing time per skill level.*
- : *Ability to run 1 additional manufacturing job per level.*

1. # Resource Processing

- : *5% bonus to mining turret yield per skill level.*
- : *5% reduction per skill level in CPU penalty of mining upgrade modules.*
- : *3% reduction in reprocess waste to all ore and ice types per skill level.*
- : *100% increase in chance of salvage retrieval per additional level.* Only affects Salvager modules, not Salvage Drones.

1. # Rigging

- : *Allows makeshift modifications to ship systems through the use of rigs. Required learning for further study in the field of rigging.*
  - Rigging skills are no longer necessary to train to install rigs, however they are important to reduce the various drawback penalties that rigs cause. Level III of this skill is the gateway to training the remainder of the skillbooks.

1. # Scanning

- : *Gives +10 Virus Coherence per level.*
- : *+5% scan strength, -5% max scan deviation, and -5% scan probe scan time per level.*
- : *Gives +10 Virus Coherence per level.*
- : *5% improvement per level in the scan speeds of ship, cargo and survey scanners.*

1. # Shields

- : *5% bonus to shield capacity per skill level.*
- : *5% reduction in shield recharge time per skill level.*
- : *5% reduction in shield upgrade powergrid needs.*
- : *Reduces the chance of damage penetrating the shield when it falls below 25% by 5% per skill level.*

1. # Social

- : *4% Modifier to effective standing from friendly NPC Corporations and Factions per level.*
- : *5% bonus per level to NPC agent, corporation and faction standing increase.*

1. # Ship Command

- : *The basic operation of spaceships. 2% improved ship agility for all ships per skill level.*

1. # Targeting

- : *5% bonus to targeting range per skill level.*
- : *5% improved targeting speed per skill level.*
- : *+1 extra target per skill level, up to the ship's maximum allowed number of targets locked.*

1. # Trade

- : *5% reduction in the costs associated with setting up a market order per skill level.*
- : *For each level of this skill the number of outstanding contracts is increased by four.*
- : *Each level increases the range from the seller to the item being sold.*
- : *Level 1 allows for the placement of orders within the same solar system, Level 2 extends that range to systems within 5 jumps, and each subsequent level then doubles it.*
- : *Each level raises the limit of active orders by 8.*
- : *Active buy/sell order limit increased by 4 per level of skill.*
