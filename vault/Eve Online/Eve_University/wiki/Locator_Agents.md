# Locator Agents

- Locator Agents**, for a fee, can find the location of another player character within a certain region (excluding **Wormholes**). Locator Agents require high **Faction Standings** to work with. Edit: Corporation standing works as well. Edit: Locator agents level 4 and 5 are available only for Omega accounts.

The players will never receive a notification that they have been located, making the service ideal for tracking down war targets or players with **Kill Rights**.

1. # Kinds of Locator Agents

The table shows that a Level 3 Agent:
- will only work for those who have at least 3.0 Faction Standing or 3.0 with the corporation
- that they can locate the target only every 15 minutes
- that if the target is in the same region as the Agent it will:
  - cost 50 000 ISK
  - take the Agent 4 minutes to send an EVEmail with the location of the target

1. # How to use Locator Agents

# Find a Locator Agent using the in game **The Agency** or **List of Locator Agents**.
# Dock with the station where the Locator Agent is located.
# Talk to the Locator Agent to open the Agent Conversation window.
# Click on the Locate Character button.
# A textbox will appear where you can write the name of the target you want to locate.
# Accept the price quote.
# Wait to receive an EVEmail from the Agent.
# Receive the target's location, when you start the search, which will include the system, constellation, region, and even station if they were docked.

The outcome also depends on the location and status of the target:
- If the target is in space, no station will be given.
- If the target is offline the Agent will give you the target's last known location, but will not tell you if they are offline.
