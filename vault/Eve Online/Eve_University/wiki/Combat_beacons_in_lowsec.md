# Combat beacons in lowsec

All listed beacons' ship limits, except for Core Military beacons, are judged by the security class of the system in which they appear in.

1. # Abandoned Battlefield
This is a beacon in lowsec that can appear anywhere.  There is only one wave of rats that spawn.

|}

1. # Derelict Ruins
Like the abandoned battlefield, only one wave of rats spawn, but deal ~100 DPS if a player warps at 0 on them.

1. # Proven Loyalty
Unlike the previous two sites, this site only appears in the Gallente-Caldari warzone and is a Core Military beacon.

Upon warp-in you will land at an acceleration gate, which supports frigates. It is not confirmed whether bigger ships are allowed by the gate.

The rats in the first pocket will aggress even if the player does not attack or is not in a militia.
