# Sansha Hidden Hub

The **Sansha Hidden Hub** is an **unrated cosmic signature combat site** that can be scanned using Core Probes in **Sansha** owned territory of Null Sec space. The site itself is a small, open area with no Acceleration Gate. There are two variations of this site, the **LCO Habitation** and **Dark Shipyard**. It is unknown whether this site can spawn a True Sansha commander ship, but it is assumed that it is possible.
