# Blood Watch

This is a combat site that can be scanned down with probes, and can be found in high security space in the Amarr regions.
The site is behind an acceleration gate.  Battlecruiser hulls and below can access it.
A passive tanked battlecruiser or faction cruiser can run this site with little difficulty.

  1. # The Site Itself

The site is gated. Warping to the site lands at 0 on the acceleration gate.
