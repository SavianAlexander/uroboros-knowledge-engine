Patch notes for EVE Online: Crucible 1.0.1

To be released Tuesday, December 6, 2011. The following are the relevant file sizes for client updates:  


- Windows from Crucible 1.0 to Crucible 1.0.1 is 8 MB
- Windows full client 4.8 GB
- Mac from Crucible 1.0 to Crucible is 1.0.1 11 MB
- Mac full client 5.7 GB



### FIXES


**Character Creation and New Player Experience**


- After you have finished with Aura's missions, she will now still refer to you by name.[//defects/issue.asp?ISID=70996](//defects/issue.asp?ISID=70996)
- Character portrait UI now remembers the previous settings - meaning you can keep the pose/expression and just make the changes you want.
- The 6th part of the first tutorial now triggers easier when walking up to the pod.


**Captain’s Quarters**


- Fixed an issue where toggling HDR could cause the map not to work when docked with _Load Station Environmen_t off.
- Racial Captain's Quarters now correctly update directly after Clone Jumping.
- If the character fails to load into the Captain's Quarters, they will automatically be moved to the ship hangar after two minutes.


**Player Owned Structures, Outposts and Stations**


- An issue with the Time Multiplier figure in Mobile Laboratories has been fixed.
- Fixed an issue where Customs Office Gantries could not be manufactured in Amarr outposts.
- Customs Office Gantries can now be located using the Directional and System Scanners.
- Player-owned Customs Offices were affected by an issue that caused their tax rate to be reset to default (5%) after downtime. This has been resolved.


**Graphics Premium**


- The message offering clone space in the Clone Vat Bay I on a Rorqual has been fixed. It said "unanchor", but now displays the correct message.


**Science and Industry**


- Filtering options for Blueprints in the science and industry window have been fixed to not hide columns.[//defects/issue.asp?ISID=70870](//defects/issue.asp?ISID=70870)


**Ships**


- An issue with fleet members using Orca corp hangars has been fixed.[//defects/issue.asp?ISID=70908](//defects/issue.asp?ISID=70908)


**Market & Contracts**


- On the welcome page for the LP store: 'receive' is no longer misspelled.[//defects/issue.asp?ISID=61668](//defects/issue.asp?ISID=61668)
- Fixed an in-space context menu for Courier Contract bookmarks.[//defects/issue.asp?ISID=70833](//defects/issue.asp?ISID=70833)
- Fixed a small error in number formatting in Courier Contracts.[//defects/issue.asp?ISID=70867](//defects/issue.asp?ISID=70867)
- Newly created Auction Contracts are not automatically 'won' now.[//defects/issue.asp?ISID=70919](//defects/issue.asp?ISID=70919)


**Agents & Missions**


- An issue with NPC's not respawning in anomalies after downtime has been fixed.[//defects/issue.asp?ISID=50365](//defects/issue.asp?ISID=50365)
- An issue with the RP/day column for Research agents has been fixed. [//defects/issue.asp?ISID=71001](//defects/issue.asp?ISID=71001)


**Corporation & Alliance**


- An issue with the 'Deliver To Member' corporation function has been fixed.[//defects/issue.asp?ISID=70818](//defects/issue.asp?ISID=70818)
- War declaration votes now display the names of included parties correctly.[//defects/issue.asp?ISID=70872](//defects/issue.asp?ISID=70872)
- Fixed the member base location string for the member details window in corporations.[//defects/issue.asp?ISID=70893](//defects/issue.asp?ISID=70893)


**User Interface**


- Trying to online/fit a module you don't have the skills for will now correctly give a message telling you what modules and skills are lacking.[//defects/issue.asp?ISID=70636](//defects/issue.asp?ISID=70636)
- Tool-tip text when hovering over assigned fighters has been made understandable to humans.
- Error message when trying to place items in orphaned jet-cans is now correctly displayed.[//defects/issue.asp?ISID=70801](//defects/issue.asp?ISID=70801)
- Time to next skill level correctly updated when adding skills to training queue.[//defects/issue.asp?ISID=70809](//defects/issue.asp?ISID=70809)
- Fixed some text overlapping in the training queue.[//defects/issue.asp?ISID=70811](//defects/issue.asp?ISID=70811)
- Calendar events between 11pm and midnight no longer create errors.[//defects/issue.asp?ISID=70831](//defects/issue.asp?ISID=70831)
- A text issue with 'Viewing the log' on station containers has been fixed.[//defects/issue.asp?ISID=70835](//defects/issue.asp?ISID=70835)
- The error message when putting certain items into containers now displays correctly.[//defects/issue.asp?ISID=70874](//defects/issue.asp?ISID=70874)
- A text issue with planetary extractors has been fixed.[//defects/issue.asp?ISID=70880](//defects/issue.asp?ISID=70880)
- Contact notifications now display the correct standings level.[//defects/issue.asp?ISID=70881](//defects/issue.asp?ISID=70881)
- Member counts in chat channel selection window are now properly aligned.[//defects/issue.asp?ISID=70925](//defects/issue.asp?ISID=70925)
- "Regional average" is now correctly spelled.
- While warping, the “Jump” command will no longer be available for all gates. It will now only be available for the gate you are currently in warp to in order to jump on contact.
- When mousing over scan probes launchers, they will no longer display their extremely impressive range on the tactical overlay.
- Jump bridges links will  no longer retain their 3d-curviness when flattening the star map.
- When reordering targets by dragging them around, the new target order will now be applied to the order used by the Next/Previous target hotkeys.
- The text buttons to increase and decrease fontsize in chat now align correctly.
- The log window now remembers it’s sorting settings.
- When you scale the UI with the map open, the “You are here” bubble will be updated with correct location.
- When you scale the UI, the text in the agent conversation now fits correctly.
- The tactical overlay will now display again on the Solar System map.
- Select/Deselect All in the Scan Filter Editor window now works correctly for the Cosmic Signature group.
- Icons on the system map are easier to see now when scanning with probes.
- The station services window now has less minimum width if you have small station services buttons.


**EVE API**


- Added factional warfare systems to the SDE with *warCombatZones* and *warCombatZoneSystems*.[//defects/issue.asp?ISID=63672](//defects/issue.asp?ISID=63672)
- Wallet journal entries and transactions are now displayed correctly.[//defects/issue.asp?ISID=70987](//defects/issue.asp?ISID=70987)


**EVE Voice, Mail & Chat**


- Join channel (when manually typing name) now correctly places you in a channel if it already exists (eg E-UNI, Invention etc).[//defects/issue.asp?ISID=70819](//defects/issue.asp?ISID=70819)


**Localized Clients**


- The 'Always Use English Voice' option now works as intended. Although a client restart is required.


**NPCs**


- Dread Guristas Irregular are now named correctly in the overview.[//defects/issue.asp?ISID=70983](//defects/issue.asp?ISID=70983)


**CONCORD and Kill Mails**


- CONCORD no longer considers you a criminal when someone you attacked over 15 minutes ago is killed by someone else.[//defects/issue.asp?ISID=51462](//defects/issue.asp?ISID=51462)


**Miscellaneous**


- Fixed the context menu for 'deliver to members' in the corp deliveries hangar.[//defects/issue.asp?ISID=70869](//defects/issue.asp?ISID=70869)
- The formatting on the client update notification has been made a little prettier.[//defects/issue.asp?ISID=70928](//defects/issue.asp?ISID=70928)
- Fixed a bug that was blocking Japanese text in ship fittings.
- Jetcan mining should now work again when you are in the same fleet, corporation or have excellent standing from the owner of the can.
- Drones guarding an Interdictor dropping a warp disruption bubble should no longer start shooting that Interdictor.
- XL hybrid turrets will now set their effect color properly based on what sort of charge is loaded.
- Some players were experiencing long delays when opening the star map.  It should now be significantly faster.



### CHANGES


**Player Owned Structures, Outposts and Stations**


- Newly installed outpost upgrades now have manufacturing lines as *public access* by default.
- Warp Scrambling Battery and Warp Disruption Battery now correctly online in 120 seconds rather than 150 seconds.
- Fuel blocks can now be placed into the appropriate racial Control Tower fuel bays alongside regular fuel types, in preparation for the forthcoming switchover.


**Weapons and Ammunition**

Hail has had its falloff penalty partially reinstated to 25%.

**Miscellaneous**


- On changing currency, you now need to reload the wallet journal.[//defects/issue.asp?ISID=67712](//defects/issue.asp?ISID=67712)
- A text issue with the market export documents has been fixed.[//defects/issue.asp?ISID=70877](//defects/issue.asp?ISID=70877)
- A bidding issue with Auction contracts has been fixed.[//defects/issue.asp?ISID=71013](//defects/issue.asp?ISID=71013)
- When trying to perform an action you don't have the skills for, your are properly notified of the cause.[//defects/issue.asp?ISID=71015](//defects/issue.asp?ISID=71015)
