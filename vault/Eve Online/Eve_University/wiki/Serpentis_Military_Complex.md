# Serpentis Military Complex

- Serpentis Military Complex** is an **unrated complex** that can be found in null-sec. It contains two rooms.

1. # Walkthrough
This combat site can be quite challenging solo without high skills and good modules. It can be done in a good drone boat, like the Gila or Ishtar.
- In the first room you want to clear out all the NPCs before attacking the Gate Scrambler.
- The second room can be quite challenging, since the waves arrive pretty fast on a timer. You want to kill of the frigates first because they scram you, so you can warp off if needed.

1. # First Room
It is possible to skip this entire room by flying to the gate, destroying the gate scrambler and using the gate to go to the next part. Doing so requires a good tank.
