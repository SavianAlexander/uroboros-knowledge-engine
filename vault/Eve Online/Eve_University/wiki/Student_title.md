# Student title

1. # The **Student Title** is a title that is applied to members of EVE University once they have been in the corporation for two weeks.  The title is manually applied by a Director around 14-16 days after you join EVE University; there is no need to apply for this title.
It provides the following access:

- Access to be able to reimburse yourself and other corporation members with the **Skillbook Program**
- Access to **The +3 Implants Program**
- Access to up to 5 half price barges through the **Half Price Barge Program**
- Access to be able to make use of our **Blueprint Library**
- Permissions to add events to in-game calendar (please note that this should only be done **in addition** to using our main [Discord Calendar](https://wiki.eveuniversity.org/EVE_University_Calendar)
