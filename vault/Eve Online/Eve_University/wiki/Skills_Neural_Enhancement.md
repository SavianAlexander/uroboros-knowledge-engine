# Skills:Neural Enhancement

# Overview
This contains all **booster**, **jump clone** and **implant** related skills.

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Advanced Infomorph Psychology|mult=yes}} | Infomorph Psychology|V}}. | Advanced Infomorph Psychology}} |
| Biology|mult=yes}} | 20% bonus per level to attribute booster duration. | Biology}} |
| Cloning Facility Operation|mult=yes}} | Enables operation of Clone Vat Bay modules. | Cloning Facility Operation}} |
| Cybernetics|mult=yes}} | Enables use of more advanced **implants**. | Cybernetics}} |
| Elite Infomorph Psychology|mult=yes}} | Increases maximum number of jump clones by 1 per level. | Elite Infomorph Psychology}} |
| Infomorph Psychology|mult=yes}} | Enables creation of jump clones. Increases maximum number of jump clones by 1 per level. | Infomorph Psychology}} |

| Neurotoxin Recovery|mult=yes}} | 5% reduction per level in chance to experience side effects of combat boosters. | Neurotoxin Recovery}} |
