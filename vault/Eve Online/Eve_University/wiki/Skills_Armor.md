# Skills:Armor

The Armor category contains the key skills for Passive and Active **Armor Tanking**.

Most combat pilots will want to train at least some of the Armor Tanking skills.

The following are the skills in the Armor section (in alphabetical order):

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Advanced Armor Layering|mult=yes}} | Advanced skill at installing upgraded armor plates efficiently and securely | Advanced Armor Layering}} |
| Armor Layering|mult=yes}} | Skill at installing upgraded armor plates efficiently and securely. | Armor Layering}} |
| Capital Remote Armor Repair Systems|mult=yes}} | Allows use of capital-sized remote armor repair modules. | Capital Remote Armor Repair Systems}} |
| Capital Remote Hull Repair Systems|mult=yes}} | Allows use of capital-sized remote hull repair modules. | Capital Remote Hull Repair Systems}} |
| Capital Repair Systems|mult=yes}} | Allows use of capital-sized local hull and armor repair modules. | Capital Repair Systems}} |
| EM Armor Compensation|mult=yes}} | Bonus to EM armor plating. | EM Armor Compensation}} |
| Explosive Armor Compensation|mult=yes}} | Bonus to explosive armor plating. | Explosive Armor Compensation}} |
| Hull Upgrades|mult=yes}} | Bonus to armor hit points. Also enables certain modules, like Expanded Cargoholds and Inertial Stabilizers. | Hull Upgrades}} |
| Kinetic Armor Compensation|mult=yes}} | Bonus to kinetic armor plating. | Kinetic Armor Compensation}} |
| Mechanics|mult=yes}} | Bonus to structure hit points. | Mechanics}} |
| Remote Armor Repair Systems|mult=yes}} | Allows use of remote armor repair modules. | Remote Armor Repair Systems}} |
| Remote Hull Repair Systems|mult=yes}} | Allows use of remote hull repair modules. | Remote Hull Repair Systems}} |

|reqV= 400/800/1600/25000mm Tech 2 Armor Plates; Tech 2 Armor Hardeners; Tech 2 Energized Membranes; 
|notes=The raw armor hitpoints bonus from this skill is very useful. Which you should probably do anyway for the hitpoints bonus.
