## Overview
Hardware Upgrade Patch Features Deployment of 70 dual-core, dual-CPU AMD Opteron LS20 Blades in 5 new IBM Blade Center Chassis. Preparation for the installation of a second RamSan-400. Changes Updated the EVE client with the new IP address of the Tranquility Cluster Hardware.

---

**Hardware Upgrade Patch**

**Features**


- Deployment of 70 dual-core, dual-CPU [AMD Opteron LS20 Blades](//www-03.ibm.com/systems/opteron/ls20/) in 5 new [IBM Blade Center Chassis](//www-03.ibm.com/systems/bladecenter/chassis/bladechassis/index.html).
- Preparation for the installation of a second [RamSan-400](//www.superssd.com/products/ramsan-400/).


**Changes**


- Updated the EVE client with the new IP address of the Tranquility Cluster Hardware.
