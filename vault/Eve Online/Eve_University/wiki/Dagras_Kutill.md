# Dagras Kutill

- Dagras Kutill** is a level 3 Minmatar Republic mission agent in **Minmatar COSMOS** located at The Carnival in Barkrik.

As this agent is part of an npc faction people can be in, its possible to have -2 corp standings, which requires you to get higher standings before missions can be accepted.
