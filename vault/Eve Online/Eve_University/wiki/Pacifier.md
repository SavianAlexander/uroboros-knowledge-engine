1. # Summary
A 1-run **Pacifier** BPC can be obtained as a recruiter benefit, for recruiting two friends, via CCP's [Recruit a Friend program](https://www.eveonline.com/recruit)The Pacifier was issued to all **Fanfest** 2017 ticket purchasers. A single run blueprint copy is given as a reward for reaching level 50 in **Project Discovery**. The Pacifier's bonuses allow it to use all types of small weaponry with equal effectiveness. Its perfectly balanced resist profile and hit-point layout allow it to be either armor or shield tanked. The Pacifier has an active tanking bonus linked to the pilot's security status. Like all CONCORD ships, the Pacifier receives a 10% bonus to security status gains from the destruction of non-capsuleer pirate ships.
