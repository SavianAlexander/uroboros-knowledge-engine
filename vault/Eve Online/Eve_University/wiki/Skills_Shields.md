# Skills:Shields

# Overview
This group has all the skills related to/required for remote and local **shield tanking**

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Capital Shield Emission Systems|mult=yes}} | Allows use of Capital Shield Transfer Array. Bonus to Capital Shield Transfer Array cap use. | Capital Shield Emission Systems}} |
| Capital Shield Operation|mult=yes}} | Allows use of Capital Shield Boosters and other Capital Shield Modules. Bonus to Capital Shield Booster cap use. | Capital Shield Operation}} |
| EM Shield Compensation|mult=yes}} | Percent Bonus to EM Resistance amount of passive shield hardeners. | EM Shield Compensation}} |
| Explosive Shield Compensation|mult=yes}} | Percent Bonus to Explosive resist amount of passive shield hardeners. | Explosive Shield Compensation}} |
| Invulnerability Core Operation|mult=yes}} | Allows use of and increases the duration of the **Rorqual**'s Pulse Activated Nexus Invulnerability Core. | Invulnerability Core Operation}} |
| Kinetic Shield Compensation|mult=yes}} | Percent Bonus to Kinetic resist amount of passive shield hardeners. | Kinetic Shield Compensation}} |
| Shield Compensation|mult=yes}} | Bonus to Shield Booster Capacitor use. | Shield Compensation}} |
| Shield Emission Systems|mult=yes}} | Allows use of Shield Transfer Arrays. Bonus to Shield Emissions System module cap use. | Shield Emission Systems}} |
| Shield Management|mult=yes}} | Bonus to ship shield amount. | Shield Management}} |
| Shield Operation|mult=yes}} | Allows use of Shield Boosters. Bonus to shield recharge time. | Shield Operation}} |
| Shield Upgrades|mult=yes}} | Allows use of shield upgrade modules. Bonus to Shield Upgrade modules Powergrid use. | Shield Upgrades}} |
| Tactical Shield Manipulation|mult=yes}} | Reduces chance of damage bleeding through to armor when shields are low. Allows use of shield hardeners. | Tactical Shield Manipulation}} |
| Thermal Shield Compensation|mult=yes}} | Percent Bonus to Thermal Resist amount of passive shield hardeners. | Thermal Shield Compensation}} |
