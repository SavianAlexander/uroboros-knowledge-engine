# Intro To ESI (Class)

<onlyinclude></onlyinclude>
1. # Class Overview
This class gives a basic top-level view of what the **ESI** is and how it works, utilizing a brief introduction through the Excel EVE Online add-on

This class covers the following topics:

- What is the ESI?
- How to use the EVE Add-On for Excel
- How the Excel add-on connects to the ESI end points and the relationship
- A brief overview of the endpoints and how one might use them
- A brief touch on "Dogma", the SDE, and other resources such as Fuzzworks, EveRef, and Zkill
- A basic overview of how **SSO** and OAuth2 flows work
- An example repo utilizing both public and private endpoints.
