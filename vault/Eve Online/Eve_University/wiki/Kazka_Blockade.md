# Kazka Blockade

- Kazka Blockade** is a static **Caldari COSMOS** site in system of Otomainen. It can be located by scanning the signature in system. It is a static site so the signature will never despawn or move. When scanning it is located right at Otomainen XI and it shows as a combat site on the probe scanner.
