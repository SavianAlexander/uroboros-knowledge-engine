# Waylaid Couriers

The **Waylaid State Couriers** is a combat site that can be found for the **Shipcaster Shadow War**.

1. # Finding the site
The site appears as a combat site and is found in the **Aokinen** constellation, in the **Minnen** constellation, and in the **factional warfare** systems controlled by the Caldari.

Only T1 and Navy Faction frigates or destroyers can enter these sites.

Inside the site there will also be a number of frigate and destroyer NPCs spawning. 
5 groups of 5 NPCs will spawn in waves while running the site. 
The groups will contain a number of Mercenary Raptors, Mercenary Hyenas, Mercenary Crows, Mercenary Cheetahs, Mercenary Wolf, Mercenary Draugur.

1. # Site contents
After destroying all the hostile spawns, 5 Caldari Claassified Courier Wrecks will spawn.
Each of these will have to be salvaged successfully to unlock the can, and it will contain the necessary Transport Relay Technology contents.

1. # Loot from the site
Loot found in a single site so far (15:09, 15 March 2023 (UTC)) has been:
- Transport Relay Datacore Blueprint
- Covert Research Tools
- Transport Research Data Fragment
- Transport Relay Research Index File
- Decryptors
- Tier 1 Salvage
