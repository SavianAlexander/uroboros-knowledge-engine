# Kochi Utrainen

- Kochi Utrainen** is an agent in one of the chains of agents in **Caldari COSMOS**. The chain consists of (ordered):
- **Akira Helkelen**
- **Ryoke Aura**
- **Goru Nikainen**
- **Kochi Utrainen**
- **Hitami Magye**
- **Mintu Oshima**
Each agent in the chain provides items required for starting or completing missions for the next agent in the chain.
