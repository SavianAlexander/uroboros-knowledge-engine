# Ship Roles (CORE class)

__NOTOC__<onlyinclude></onlyinclude>
1. # Class Overview
Introduction to Ship roles teaches the basics of fitting a ship for a specific role in EVE Online and gives recommendations and priorities in fitting for different general areas of the game.

This CORE class covers the following topics:

- The Golden Rule
- Discussion of Fits and their fitting priorities for:
  - Solo PvE Roles
  - Industrial Roles
  - Misc. Roles
  - Fleet PVP Roles
- Q&A
