# List of W-space system

1. # Class 1 Wormhole Systems [Regions 1-3] (Total: 348 Systems)
Special Rules:

All class 1 systems have one static, which goes to k-space.

Wandering wormholes departing class 1 go to w-space.

No ship with greater than 20,000,000 kgs of mass may traverse wormholes leading to/from class 1 systems.
