# Dust 514: Corporations

1. # Corporations

These skill are required if you are a budding Megalomanic and wish to create and run your own Corporation in Dust 514.

There are just three skills but the proceeding skill must be gotten up to Level V before it unlocks the next skill.

  1. # Corporations

Cost 20,000 ISK

  - 1x Training Cost Multiplier**

Bonus: +10 corporation members allowed per level

  1. # Megacorp Control

Cost 400,000 ISK

Requires Corporations Level V

  - 3x Training Cost Multiplier**

Bonus: +50 corporation members allowed per level

  1. # Transstellar Empire Control

Cost 8,000,000 ISK

Requires Megacorp Control Level V

  - 5x Training Cost Multiplier**

Bonus: +200 corporation members allowed per level

1. # Corporations Created in EVE Online

Another way to create a corp is if you have an existing character in EVE Online who has any Corporation skills already learned.

A very effective way to go about Corp creation is to employ the services of a player in EVE who has their Corp skills maxed out. Using this method it is possible to have a corporation that can have 6300 members. Once they have created the corp for you, any character in either EVE or Dust 514 who has just the Corporations at Level I, can be made CEO. This saves the grind of using SP to learn the skills required to run a large corp.

Its also a way to increase the size of your membership beyond that which can be done just in Dust 514. With maxed out Corporation Skills on a Dust character, the most members it can control is just 1300. 5000 less than an EVE created Corp using maxed skills.
