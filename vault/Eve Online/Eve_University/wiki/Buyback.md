# Buyback

The Buyback Program is simply a way to sell your loot easily without the hassle of having to haul it to a trade hub yourself. You can use this program if you want to liquefy your own assets from missions, salvaging, exploration, PI (or any other way of acquiring stuff you can think of), instead of having to haul it all to market and sell it yourself. The Buyback Program buys from Unistas at a rate between 95% and 85% of Jita Buy value, with the profit made off selling these items making up the brunt of the funding that goes into the various [services](https://wiki.eveuniversity.org/Category:EVE_University_Services) members of EVE University can enjoy.

1. # Buyback instructions
Buyback appraisal is handled through an Alliance Auth Buyback Program module. This module allows for different items to be appraised in different ways within the same contract. For example, ores are calculated using refined value, NPC loot is calculated using NPC values and other items are calculated using Jita values. As a result, you can send all types items through the Buyback Program in one contract. For group fleets the Fleet Commander or an appointed individual can submit a single buyback contract with the entire fleet's loot and pay out individual fleet members manually once the buyback contract is accepted.

When setting up buyback contracts please be mindful that each contract has to be checked to a degree by a player volunteering their time. Therefore, the department kindly asks you to minimize the number of contracts were possible. Example: If you have compressed ore and mission loot to sell the rules for these goods demand contracts in different locations and setting up two contracts is absolutely fine (and required). There is also a limit of 500 stacks per contract, so if you are selling a lot of different items a second contract may be in order. However, setting up a contract for loot from each site or mission or for each gas anomaly creates avoidable workload for the department. Please accumulate your takings and set up the respective contracts at the end of the day or week. 

  1. # Prepare your items

# Format the items in your Item hangar into list format
# The items you want to contract need to be in your hangar (not in containers)
# Make sure they are not damaged (Select All, right-click them and select 'Get Repair Quote' if available, then 'Repair All' if anything shows up as damaged)
# Make sure everything is (re)packaged (Select all and right-click them, select '! Repackage' if available)
# Select all, right-click the items and select 'stack all'

  1. # Calculate the value
# Select all the items you want to contract to Buyback (press  +  to select all if so desired)
# Press  +  to copy the list to your clipboard (right clicking and selecting "Copy" doesn't work properly)
# Open the [Alliance Auth Buyback Programs module](https://auth.eveuniversity.org/buybackprogram/) and select 'Use' for the correct Buyback Program for your location and item type
# Then CTRL + V to paste it into the submission form.
# Click 'Calculate'
# The value of your buyback will be under Contract settings near the top of the page beside 'I will receive'
# Briefly review the calculation page. The contract value and description are under 'Contract settings', labelled 'I will receive' and 'Description' respectively. If there are any red icons in the item details section you may have included items not accepted by the program which will not be paid out. To remove these items from the submission return to step 1 and alter the selection. Removing the items during contract creation may result in your contract being rejected.
# Keep the calculation page open, we will need information from the Contract settings for creating the contract
Note: the image below points out a set of "copy to clipboard" buttons to the right of the contract settings: Use this button to copy the description rather than highlighting and copy+paste to avoid invalid descriptions

  1. # Create the actual contract
# Once again, select all the items you want to contract to the Buyback Program
# Right-click them and select 'Create Contract'
# For 'Contract Type' you want to select 'Item Exchange'
1. . For 'availability' select 'Private', and for the name type 'Ivy League Buyback'
# Click the 'Next' button
# A list of items will appear, with an X by the ones you are about to put into the contract (adjust X's as needed)
# Click the 'Next' button
# On the 'I will pay' box make sure it’s set to 0.0; (this is a FREE service!)
# On the 'I will receive' box make sure it’s set to the 'I will receive' value from the alliance auth Buyback module
# Set expiration to 4 weeks (don't worry, it will not take that long at all)
# In the Description field, paste the description from the buyback module. Make sure to use the button to copy the description from AA to avoid copying invisible characters
# Click the 'Next' button

  1. # Common errors and how to avoid them
- If you highlight the description and copy + paste from a highlight, it may copy invisible characters that may lead to the contract not being tracked correctly. Instead, use the copy to clipboard button to the right of the description field to copy only the intended description
- If you delete a contract and recreate it using the same description, the Buyback Program module will not track the re-created second contract. If you need to recreate a contract, recalculate the contract price to get a new description so the new contract will be tracked under the new description

  1. # Rules & limitations
# No damaged or assembled goods, all goods must be repackaged and stacked
1. * Keep in mind that used mining and frequency crystals are considered to be damaged, so they cannot be repackaged and are thereby not to be put into Buyback contracts (feel free to donate those via the Community donations cans)
# Contract price should be set correctly
1. * If the price you have set is too high, we will reject the contract
1. * If the price is too low by less than a million and also less than 1% of the total contract value, we will accept it anyway, to save some time for all parties involved
# High volume, low value items such as P0, P1, Tritanium and Pyerite are not accepted outside of tradehub locations due to difficulty in hauling said items. 
1. *If you wish to sell items like this, please make arrangements directly with other members using the #buy-or-sell channel in discord
# Items with limited market history may not receive payouts until sufficient data is available. 
1. * This normally occurs for new items.
1. * To see if any of your items are impacted, check for red icons on the right side of the Item Details section of the contract calculator
# We reserve the right to reject event loot during the first weeks of the event. Sometimes, the initial market price is very high at the beginning and declines rapidly after a few days
# We reserve the right to reject large quantities of items with high value and low trade volume. 
1. * Sometimes items have very high price estimations that are the result of a small volume buy order in jita.
1. * If you want to dump lots of LP it is better to ask beforehand if we are willing to accept the items for the Janice price. This happens very rarely but we have to do this if we don't want to potentially lose billions of ISK
# We reserve the right to reject contracts if the market prices differ too much from appraisal prices
