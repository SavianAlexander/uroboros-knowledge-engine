# Booster Manufacturing (Sooth Sayer)

<noinclude> 
  - Minmatar COSMOS** mission
Agents: **Riluko Hik**, **Uiswin Aurtur**, **Zwod Aden**
Standings required: None

  - Booster manufacturing** is a single run mission found in null security COSMOS constellations. Each agent will give this mission only once.</noinclude>

Simple trade mission where the agent requests some Cytoserocin and gives a drug BPC as a reward. The gas can be mined locally if you have a **Venture** or **Prospect** and core probes. Alternatively you can use a blockade runner or prospect to haul the gas from elsewhere. This mission can be completed once for each agent (**Riluko Hik**, **Uiswin Aurtur**, **Zwod Aden**).
