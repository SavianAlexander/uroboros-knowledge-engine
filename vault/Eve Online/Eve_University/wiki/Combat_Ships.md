# Combat Ships

Combat ships are often categorized by:
- Use - PvP or PvE
- Size - e.g., frigate, cruiser, battleship
- Fitting and role - missile, drone, tackler, brawler

  - EVE ships** shows all EVE ships in a convenient table format. The bulk of these are combat ships.

Other specialised lists:
- **Drone-capable ships**, for ships using **Drones**
- **Missile ships**, for ships using **Missiles**
- **List of PvP Ships by Bonus**
- **Mission Ships**
- **Ship Class Tactical Overview**, a quick reference for PvP pilots
