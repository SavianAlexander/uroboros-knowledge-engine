**Miscellaneous Fixes and Improvements**


- Additional German translations have been added into the client.
- Several server-side optimizations and fixes have been made.
- **Chat:** It will no longer be necessary to click the scroll bar in order to scroll text in the chat window.
- **Overview:** Wrecks are no longer shown in an empty state after changing column width in the overview.
- **Overview:** Distance to a wreck that has been looted will update properly.
- **Overview:** The Angular Velocity column displays the proper value and not Rotational Velocity.
- **Overview:** Resizing columns will no longer leave artifacts in the window.
- **Tactical Overlay:** The marker from ship to target will display properly.
