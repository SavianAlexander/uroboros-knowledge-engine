# Dark Blood Fleet Staging Point

The **Dark Blood Fleet Staging Point** is an **unrated cosmic signature site** that can be scanned using Core Probes in **Blood Raider** infested regions of Null Sec space. It may also be received as an **escalation** from **Blood Forsaken Hub** and 
  - Blood Forlorn Hub** anomalies. The site itself escallates twice, involving travel. If both escallations go in the same direction, you could end up in hostile space for part 3.

This can be run in a single Ishtar. The site appears to not aggro on Ishtar drones, so reset the aggro if that happens. The most critical part of running this is to deal with the neut batteries. Primary them but run away while you do because incoming damage will be heavy and you won't have cap. Fits with 100mn ABs and especially drone navigation modules, to get to the neut batteries faster may be best. Note that non-capital dark blood modules vary widely in price and so the site may not be worth running. It takes a long time. I destroyed all the batteries, but I recommend only destroying the neut batteries.
