# Skills:Resource Processing

This group has all mining, harvesting and reprocessing skills. Resource processing skills gave memory and intelligence as their **attributes**. As you might suspect, the core of any budding industrialist and/or miner. It does not include any combat skills, so can be mostly ignored by PvP'ers and PvE'ers alike.
