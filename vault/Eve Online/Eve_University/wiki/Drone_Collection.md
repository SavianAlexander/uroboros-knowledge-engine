# Drone Collection

- Drone Collection** is a **combat anomaly** inhabited by **Rogue Drones** that can be found in high security space.
1. # Walkthrough
Single normal space pocket. Auto-aggression from each wave. The last drone killed triggers the next wave. Waves spawn at 5-8 km from warp-in
