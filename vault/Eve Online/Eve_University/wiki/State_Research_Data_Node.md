# State Research Data Node

The **State Research Data Node** is a **data site** that can be scanned down for the **Shipcaster Shadow War**.

1. # Scanning down the site
The site appears as a data site and is found in **factional warfare** systems controlled by the appropriate faction and also in high security space of specific constellations.

| -
! Faction !! Additional High-Security Constellations |
| :--- |
| State Research Data Node |
| Republic Research Data Node |
| Imperial Research Data Node |
| Federation Research Data Node |

Only T1 and Navy Faction frigates can enter these sites. **Astero**s are unable to enter, same goes for any **Covert Ops Frigate**.

1. # Entering the site

| **56px|link=** | **WARNING:** Upon entry you will be given a **suspect timer**, meaning you are a viable target for attack by other players. |
| :--- | :--- |

| **56px|link=** | **WARNING 2:** These NPC rats will warp scramble you, web you, neut you, and warp disrupt you. If you are undertanked, you will die. |
| :--- | :--- |

| **56px|link=** | **WARNING 3:** Upon entry a beacon will be placed in the site, making it possible to warp to the site without scanning it down. While killing the rats you are in a lot of danger and should watch D-Scan rigorously. |
| :--- | :--- |

Inside the site there will also be a number of frigate NPCs spawning. 5 groups of 5 frigate NPCs will spawn in waves while running the site. The groups will contain a number of Crow Mercenaries and Cheetah Mercenaries.

**Crow Mercenary : These ones warp disrupt and try to keep range, but a regular afterburner should be able to catch up to them**:

**Cheetah Mercenary : These come in close range and do considerable damage with webs, warp scramble, and neuts.**:
