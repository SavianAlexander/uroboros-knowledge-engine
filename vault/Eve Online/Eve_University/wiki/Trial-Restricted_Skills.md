# Trial-Restricted Skills

With a trial account, there are a number of skills which are restricted, and cannot be trained. Having any of these skills injected (ie: at level 0 with 0 SP) is not possible for a trial account and as such these are all classed as demonstrating that the character is not using a trial account.

Note that while there are other skills which are not listed here, they have one or more prerequisites listed below, meaning they could not be trained.__NOTOC__

- Advanced Spaceship Command
