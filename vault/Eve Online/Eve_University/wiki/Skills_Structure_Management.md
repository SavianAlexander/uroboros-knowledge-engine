# Skills:Structure Management

# Overview
This skill category contains skills involving the anchoring and utilization of deployable structures of all sizes, from player-owned starbases to **citadels**. These skills also allow the control of starbase and citadel weapon systems.

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Anchoring|mult=yes}} | Base skill required to anchor objects in space. | Anchoring}} |
| Mercenary Den Management|mult=yes}} | Allows operation of 1 MD per level | Mercenary Den Management}} |
| Starbase Defense Management|mult=yes}} | Allows control of POS weapon systems. | Starbase Defense Management}} |
| Structure Doomsday Operation|mult=yes}} | Skill at using structure doomsday weapons. | Structure Doomsday Operation}} |
| Structure Electronic Systems|mult=yes}} | Skill at using structure support modules. | Structure Electronic Systems}} |
| Structure Engineering Systems|mult=yes}} | Skill at using structure support modules. | Structure Engineering Systems}} |
| Structure Missile Systems|mult=yes}} | Skill at using structure missile weapons. | Structure Missile Systems}} |
