# Blood Raider Outpost

The **Blood Raider Outpost** is an **unrated cosmic signature combat site** that can be scanned using Core Probes in **Blood Raider** regions of Low Sec space.

The site is behind an acceleration gate. Warping to the side lands you at 0 on the gate.

A passive shield-tanked Drake can run this site.
