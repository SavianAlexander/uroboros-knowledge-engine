**EVE Voice, Mail & Chat**


- Fixed race condition when two users call each other at the same instant.
- Fixed multichannel failures with text disconnect and media disconnect.
- Resolved a number of memory leaks.
- Fixed crash upon REGISTRATION.
- Better performance of EVE Voice with crowded channels.


**Miscellaneous**


- Previous optional updates are rolled into this package. The optional updates are as follows:
- An optional client hotfix has been applied which fixes an issue with the reprocessing window not closing automatically after finishing a job. Released 19 June 2008.
- The Cache Size option in the ESC menu would always be set to High, no matter what value was selected/displayed, this has now been fixed. Note: Changing the Cache Size in the ESC menu to Low should reduce memory usage at the cost of possible longer loading times. Released 25 June 2008.
- A new instance of the warp sound was being loaded into memory each time a player warps a ship within the same solar system, these instances would pile up until he changed session. Released 25 June 2008.


**Empyrean Age 1.0.1-1 Optional Client change, released 08 July 2008**


- Fixed the usage of the prefs.ini to switch the decimal and digit settings (10,000.00 to 10.000,00) that was causing some windows not to display properly.


**Empyrean Age 1.0.1-2 Server side change, released 10 July 2008**


- An exploit concerning Faction Navy NPC's has been fixed, making EVE a better world to live in for us all.
- Several GM Tools have been updated allowing the Game Masters to assist you better.


**Empyrean Age 1.0.1-3 Server side change, released 16 July 2008**


- Starbases in high-security space will now engage pilots in enemy Militias when “Attack if at War” is set.
- Several GM Tools have been updated allowing the Game Masters to assist you better.
