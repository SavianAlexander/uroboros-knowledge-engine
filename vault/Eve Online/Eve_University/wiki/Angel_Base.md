# Angel Base

The **Angel Base** is an **unrated cosmic signature combat site** that can be scanned using Core Probes in **Angel** infested regions of Null Sec space. Estimated payout 14-18.7 mil. The site is easy with Prop mod fitted Faction, T2 or T3 Cruiser; MJD sniper Battleship.

1. # Warp-In
No Hostiles at warpin.  Activate the Acceleration Gate

1. # First room
Clear all the NPC's to access the gate.
