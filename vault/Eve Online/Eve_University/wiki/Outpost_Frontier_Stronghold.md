# Outpost Frontier Stronghold

{{whcobox|
- This site doesn't have any neuts. If you're running solo in something that has less-than-optimal cap stability, this is the site you want.
- There is fairly high alpha on the first wave due to the sentry towers plus battleship. Take the sentries out first.
- Sleepless Defenders only web out to 30km. If you're primarily speed tanking, you'll want to pull range.
- With decent skills this site can be run solo in about 20 minutes.
- Sentries do not drop loot. This can seem discouraging at first, but the battleships drop good loot, and often several melted nanoribbons.
