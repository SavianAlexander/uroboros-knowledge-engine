# Short skill plan ships

This is a list of suggested fits you can fly once you have trained the various stages of the **Short Skill Plan**. These are not EVE University doctrine ships. However, they will allow you to use a more basic version of the same ship the rest of the fleet is flying, so you can still attend fleets while you train up the skills necessary to fly the normal doctrine ships.

1. # Frigate DD Ships

You can fly the following ship fits after training the Frigate DD Basic skill plan.

  1. # Atron

  1. # Executioner

  1. # Kestrel

  1. # Punisher

  1. # Rifter

  1. # Slasher

  1. # Tormentor

1. # Cruiser DD ships

You can fly the following ship fits after training the Cruiser DD Basic skill plan.

  1. # Thorax

  1. # Caracal

  1. # Moa

  1. # Rupture

  1. # Stabber
