# Angel Domination Fleet Staging Point 3

The **Angel Domination Fleet Staging Point 3** is the final part of the **escalation** chain received from the **unrated cosmic signature site** of the same name.

1. # Walkthrough
The site consists of one open deadspace pocket. no ship restriction so supercarrier can beat this site very easy

Do not try to Blitz with subcapital. it is impossible to active tank since there is neutralizing tower.

 
 

This structure tanks over 1400+ dps
