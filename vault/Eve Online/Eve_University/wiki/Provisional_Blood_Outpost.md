# Provisional Blood Outpost

The **Provisional Blood Outpost** is an **unrated cosmic signature combat site** that can be scanned using Core Probes in **Blood Raiders** owned regions of Low Sec space.

The site is located behind an acceleration gate.  Battlecruisers (T1/T2) and below can access it.  

A passive shield-tanked Drake can run this site slowly.  The rats are not difficult, but they are very spread out, so bring a MWD.

1. # Walkthrough
Each new wave spawns when the previous one is destroyed.  All enemy waves spawn around the cluster of structures.
