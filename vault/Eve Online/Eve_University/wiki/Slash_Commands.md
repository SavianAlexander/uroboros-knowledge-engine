# Slash Commands

EVE is a game known for not having much variety of emotes or "slash" commands. The most used is simply: 

/me makes a comment
/emote makes a comment
Both result in: *** My Name** makes a comment

What it does have beyond this, are keybindings, and this list collects the majority of known commands, functional or not.

Many commands have been added or removed over the years, so assume this list is out of date and feel free to help improve the currency by discovering commands given in the Shortcuts menu. Do be careful about deciding to remove any commands, since they may appear non-functional if you are not in the correct context for the command to be used. 

  1. # Why is this list useful
It can save everyone time. It is far simpler to tell someone who is docked to "type /open overview settings" than instructing them to 1) undock, 2) click for overview settings dropdown, 3)... etc. or even 1) Open your keybind menu... etc.

If you absolutely, positively have to get someone to perform a command NOW, it is possible for them to not have the same keyboard layout or key bindings as you do. These commands are universal, and if you say "DRONES IN: type /cmd_drones_return_to_bay" you can be very confident they will be recalling their drones instead of forgetting which keybind or UI box they have to find. 

To use slash commands, type the command into any chat window preceded by a '/'. None of the commands take arguments or display errors if typed incorrectly, they do however are echoed back into the chat channel as . All are case insensitive and you can substitute spaces for the underscores. '/open_mail' and '/Open MAIL' are equivalent.
