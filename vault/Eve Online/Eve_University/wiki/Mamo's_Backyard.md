# Mamo's Backyard

- Mamo's Backyard** is a scannable combat signature [OUI-560] in Lirsautton system. It is a static site so it will always be in the same place so a **bookmark** of it never expires.

The warpin of this site houses **Mamo Guerre**, an agent in **Gallente COSMOS**. The second room contains some light combat.

1. # First room
The rats and items in this room respawn periodically.
