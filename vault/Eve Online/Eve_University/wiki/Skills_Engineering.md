# Skills:Engineering

# Overview
The Engineering category contains capacitor support skills, and **capacitor warfare** skills.

The following are the skills in the Engineering section (in alphabetical order):

| Attributes (Primary, Secondary) | Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- | :--- |
| Perception, Willpower | Advanced Weapon Upgrades|mult=yes}} | Reduces powergrid need of turrets and launchers. | Advanced Weapon Upgrades}} |
| Intelligence, Memory | Capacitor Emission Systems|mult=yes}} | Allows use of energy nosferatu, energy neutralizers, and energy transfer arrays. Bonus to cap use of these modules. | Capacitor Emission Systems}} |
| Intelligence, Memory | Capacitor Management|mult=yes}} | Bonus to capacitor capacity. | Capacitor Management}} |
| Intelligence, Memory | Capacitor Systems Operation|mult=yes}} | Allows use of cap boosters, Energy System Operations modules. Reduces capacitor recharge time. | Capacitor Systems Operation}} |
| Intelligence, Memory | Capital Capacitor Emission Systems|mult=yes}} | Allows use of Capital Energy Transfer Arrays. Bonus to Capital Energy Emissions System modules cap use. | Capital Capacitor Emission Systems}} |
| Intelligence, Memory | CPU Management|mult=yes}} | Bonus to ship CPU. | CPU Management}} |
| Intelligence, Memory | Electronics Upgrades|mult=yes}} | Allows fitting of electronics upgrades modules. Reduced Electronic Upgrade Module CPU use. | Electronics Upgrades}} |
| Intelligence, Memory | Energy Grid Upgrades|mult=yes}} | Allows use of Energy Grid Upgrade modules. Reduces CPU cost of these modules. | Energy Grid Upgrades}} |
| Intelligence, Memory | Energy Pulse Weapons|mult=yes}} | Allows use of smartbombs. Reduces smartbomb cycle time. | Energy Pulse Weapons}} |
| Intelligence, Memory | Nanite Interfacing|mult=yes}} | Increases damaged module repair amount. | Nanite Interfacing}} |
| Intelligence, Memory | Nanite Operation|mult=yes}} | Decreases nanite consumption. | Nanite Operation}} |
| Intelligence, Memory | Power Grid Management|mult=yes}} | Bonus to ship powergrid. | Power Grid Management}} |
| Intelligence, Memory | Resistance Phasing|mult=yes}} | Reduces cycle time & capacitor need of reactive armor hardeners. | Resistance Phasing}} |
| Intelligence, Memory | Thermodynamics|mult=yes}} | Enables **overheating**. Reduces damage from overheating. | Thermodynamics}} |
| Perception, Memory | Weapon Upgrades|mult=yes}} | Reduces CPU use of turrets and launchers. | Weapon Upgrades}} |

{{Skill
|skill=Thermodynamics
|desc=Advanced understanding of the laws of thermodynamics. Allows you to deliberately **overheat** a ship's modules in order to push them beyond their intended limit. Also gives you the ability to frown in annoyance whenever you hear someone mention a perpetual motion unit. Reduces heat damage by 5% per level.
|1=Intelligence
|2=Memory
|price=4.5M
|pre=, , 
|notes= Overheating active modules can have a significant effect in combat: the bonuses offered by overheating range from an increase in the damage output of weapons, larger speed boosts from propulsion modifiers, an increase in the range of certain modules, better resists, an increased rate of repair and more. A higher Thermodynamics skill allows you to overheat modules for longer before burning them out. This skill need not be a priority for a pilot who only flies in everyday PvE combat (missions, ratting). It is however useful in advanced PvE (e.g. running **Abyssals**), important in PvP, and especially important in small-gang and solo PvP.
}}
