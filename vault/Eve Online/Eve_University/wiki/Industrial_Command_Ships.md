# Industrial Command Ships

- Industrial Command Ships** directly follow the ORE Industrials section of the tech tree.  Their primary purpose is to provide support for mining fleets, usually in the form of **Command Bursts**. Though not explicitly stated in-game, Industrial Command ships as a group are immune to **Micro Jump Field Generators**.

1. # Porpoise
The Porpoise class Industrial Command Ship is a more affordable, introductory mining foreman platform.  Due to its agility and warp speed it excels at supporting fleets in more dangerous regions from Low Security Space to Wormhole Space.  The Porpoise can be as cheap as a tech one battlecruiser.  The ship also carries more or less the same bonuses as the Orca, making it a good training vessel for training into a much larger fleet support capacity.

  - Porpoise**

1. # Orca
The Orca is a more powerful mining foreman platform that can fit three command bursts, which can be extended by fitting appropriate rigs.  The ship boasts four bays; ship maintenance bay that can be used to store assembled ships, a mining hold, a fleet hangar and normal cargo hold.  This allows the Orca to not only prolong the time it can stay on grid during mining operations, but also allows it to be a formidable general purpose freighter.  The Orca's large number of mid slots allows it to fit one of the most effective tanks among hauling ships, easily reaching 400k ehp without overheating any modules.

More about the Orca and its various roles is listed in the **Orca Guide**.
