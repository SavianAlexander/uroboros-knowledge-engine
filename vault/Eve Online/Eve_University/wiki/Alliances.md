# Alliances

An Alliance is a group of **Corporations**. Multiple corporations together are able to do things which a sole corporation may not be able to do, such as hold sovereignty.

1. # Forming an Alliance

Forming an alliance costs one billion ISK, and there is an Alliance Maintenance Bill which must be paid monthly, which is two million ISK for each corporation in the alliance. So an alliance with 20 corporations would cost 40 million ISK per month in maintenance fees. The Alliance Maintenance Bill is taken from the corporation wallet of the executor coproration, and can be set up to be paid automatically each month.

To form an Alliance, you must be the CEO of a corporation which is not currently in an Alliance. You must also have the following skill:

1. # Joining an Alliance

To apply to join an alliance, go to the  window, then the  and the  tab. Find the alliance you wish to join, right-click and select . You will have an option to add some information in a free text box. You can only apply to an Alliance if you are not yet a member of another Alliance. So make sure to quit your current Alliance before applying to a new one. You can also only apply to one alliance at once, so if you have a pending application it will be withdrawn if you apply to a different alliance. Once you have submitted your application you can view it or delete under the  tab. If you try to apply again it will tell you that you already have sent an application to this alliance.

When your application has been submitted, the Executor corporation will be able to view it in  window in // tab. They do not receive a notification to tell them there has been a new application to the alliance. To accept or reject an application, they can right click on the application, click  and select to either  or  the application.

  - Note:** There is a 24 hour cool down after an alliance application is accepted before it becomes effective in-game. The application will show as accepted, but the alliance tab will indicate the corporation is not currently part of an alliance.

1. # Leaving an Alliance

To leave an alliance, open the  window. Then within the Corporation window, go to the "" tab. Select the "Members" sub-tab to see a list of member corporations in the alliance. Right-click on your own corporation's name from the list. Choose "Quit alliance" from the context menu that appears. A confirmation prompt will appear; select "Done" to complete the process.

1. # Alliance administration

Each alliance has an Executor Corporation, who deal with the administration of the alliance. To be an Executor, the corporation must have the support of the CEOs of at least 50% of the member corporations. To support an Executor corporation, the CEO must go to the  window, then the  and the  tab, select a member corporation from the list and click . The Executor corporation will be displayed in the Alliance Attributes.

The Executor corporation is responsible for paying the Alliance Maintenance Bill, and if this is ever unpaid, the alliance will be closed at the following downtime. It is therefore  to ensure this bill is paid. It can be set up to be paid automatically under the **bill pay settings**.
