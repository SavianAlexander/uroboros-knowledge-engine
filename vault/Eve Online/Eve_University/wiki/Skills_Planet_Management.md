# Skills:Planet Management

# Overview
  - Planetary Industry** (PI) core skills.

Intelligence, Memory and Charisma are vital to learning to manage planet colonies.

The following are the skills in the Planetary Industry section (in alphabetical order):

| Skill (Multiplier) | Purpose | Alpha Limit |
| :--- | :--- | :--- |
| Advanced Planetology|mult=yes}} | The skill further increases the resolution of resource data when scanning a planet to allow for very precise surveying. (Requires Planetology IV.) | Advanced Planetology}} |
| Command Center Upgrades|mult=yes}} | Unlocks more advanced Command Centers. | Command Center Upgrades}} |
| Interplanetary Consolidation|mult=yes}} | Each rank allows the control of one additional planet. | Interplanetary Consolidation}} |
| Planetology|mult=yes}} | The skill increases the resolution of resource data when scanning a planet to allow for more accurate surveying. | Planetology}} |
| Remote Sensing|mult=yes}} | The ability to gather and analyze remote sensing data from satellites in orbit around a planet and to produce proper calibrated surveys. | Remote Sensing}} |
