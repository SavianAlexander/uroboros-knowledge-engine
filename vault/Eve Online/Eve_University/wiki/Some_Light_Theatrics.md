# Some Light Theatrics

<noinclude>  </noinclude>

Video: [[Probe](https://youtu.be/VICYK0FqyBE) January 2021]

Ungated deadspace pocket one jumps away in the same System.

Hack the CPF Habitation Module with a Data Analyzer and grab the CPF Security Personnel (15 m3). CPF Habitation Module will explode thirty seconds after you've hacked it. The explosion damages ships in 10 km range.

Tips:
- Do not warp out before the CPF Habitation Module explodes
- If you let the CPF Security Personnel explode inside the CPF Habitation Module you will fail the Epic Arc
