# AICPA SOC 2 Type II Trust Services Criteria

### CC6.1 - Logical and Physical Access Controls
The entity implements logical access security software, infrastructure, and architectures over protected data and systems.
### CC6.6 - Boundary Protection & Data Ingress/Egress
The entity implements boundary protection mechanisms to prevent unauthorized data exfiltration and ensure zero-redaction empirical traceability.
### CC6.8 - Cryptographic Hash Verification & Tamper Detection
The entity implements SHA-256 cryptographic hash trees (Merkle Trees) and automated provenance verification across all deployed production releases.
### CC7.1 - System Operations & Infrastructure Monitoring
To meet its objectives, the entity uses detection and monitoring procedures to identify changes to system configurations, data stores, and integrity.
### CC8.1 - Change Management & Cryptographic Provenance
The entity authorizes, designs, develops or acquires, configures, documents, tests, approves, and implements changes using immutable Merkle trees.
### PI1.1 - Processing Input Validation & Determinism
The entity obtains or generates, uses, and communicates relevant, high-quality information regarding the definition of data processing inputs, calculations, and rule outcomes.
### PI1.5 - Immutable Test Execution Evidence
The entity maintains complete, unalterable execution logs and signed acceptance certificates for all statutory benefit calculations.
