# Agent Inquiry

<noinclude>
</noinclude>

Another very easy mission - just fly to the agent in [Tar](https://evemaps.dotlan.net/system/Tar) and start a conversation.
For people having trouble with this mission, the way you "report" to the agent is by selecting him from your PvE overview, then clicking the sound like shaped icon in the selected item window. If this button isn't visible, then you probably have the beacon selected instead. Try switching overviews.
