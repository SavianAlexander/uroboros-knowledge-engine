# Gurista Surveillance Squad

- Gurista Surveillance Squad** is an **Expedition** that can escalate from **Provisional Gurista Outpost**.
1. # Walkthrough
Video: [First location](https://www.youtube.com/watch?v=5AO2WtEQYco&t=6s), [Second location](https://www.youtube.com/watch?v=xP5wpbPOOUc),[Third location](https://www.youtube.com/watch?v=TuAJ6vTYH74),[Final location](https://www.youtube.com/watch?v=Yp3XAupRdvI)
  1. # First Location(lowsec)
If Dread Guristas does not spawn, take the Newly Constructed Acceleration Gate into the second room and destroy the Guristas security station.
